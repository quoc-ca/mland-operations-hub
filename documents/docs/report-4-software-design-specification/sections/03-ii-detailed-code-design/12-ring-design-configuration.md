### 12.5 Current configuration-assistance controls

The Ring Configuration screen includes a size-guide modal with the reference chart, circumference/diameter instructions and an interactive size table for sizes 6–29. A hand/ruler reference image can be previewed locally for comparison and is not persisted as part of the design. Laser engraving also offers six built-in quick presets—clover, heart, sun, moon, star and infinity—which are rasterized to PNG data and consume the existing two-image engraving limit.
