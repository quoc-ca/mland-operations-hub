### 2.1 Caching Strategy

Manager navigation badge counts are kept for 30 seconds and refreshed every 60 seconds while the page is visible. If a count cannot be read, its badge is hidden; it is not shown as zero.

The Manager dashboard reloads on page entry, filter application, or page reload. It shows the last successful update time and does not refresh on a timer.

Cached role information may control what the browser displays, but the server checks current Account status, role, and location scope before sensitive actions. Checkout and booking check current business values before acceptance. No shared server cache or cache lifetime is defined for those values.
