## 4.1 Major Features

| ID | Feature Name | Description | Addresses Gap |
| --- | --- | --- | --- |
| FE-01 | Location and Slot Management | Staff define workshop locations, session windows, capacity, and bookable availability for each operating day. | GAP-01 |
| FE-02 | Customer Self-Service Booking | Customers choose a location and available session slot, then submit a booking request without relying on a call or direct message. | GAP-01 |
| FE-03 | Booking Administration and Attendance | Staff confirm, update, cancel, and mark attendance for reservations from one shared operational record. | GAP-01, GAP-03 |
| FE-04 | Staff Shift Scheduling | Managers publish shifts by location so customer-service staff can see assigned coverage and schedule changes. | GAP-02 |
| FE-05 | Multi-Location Operations Dashboard | The owner and authorised managers view booking volume, upcoming sessions, and staffing coverage across locations. | GAP-01, GAP-02 |
| FE-06 | Immutable Operational Audit Log | MOH records key booking and shift changes with actor, timestamp, action, and affected record for later review. | GAP-03 |
