# 4. Project Scope & Limitations

The active V1 baseline begins on 15 September 2026. It is centred on a customer journey for personalised rings: group-session booking, optional design before or during consultation, feasibility decision, estimate, fulfilment, and collection payment. Details without supporting evidence remain open rather than becoming commitments.
