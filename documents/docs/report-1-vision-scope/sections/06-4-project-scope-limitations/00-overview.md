# 4. Project Scope & Limitations

The active V1 baseline begins on 15 September 2026. It is centred on a customer journey for personalised rings: group-session booking, optional design before or during consultation, feasibility decision, estimate, fulfilment, and collection payment. Group decisions on 17 and 18 September approve the booking/session rules, attendance-fee boundary, continuation/custody direction, catalogue/AI routing, conditional Google review import, and no-expiry ready-ring reservation described in this report. Exact operating data and unresolved integration/governance rules remain open rather than becoming commitments.
