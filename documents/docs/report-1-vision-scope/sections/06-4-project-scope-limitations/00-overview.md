# 4. Project Scope & Limitations

The active V1 baseline begins on 15 September 2026. It is centred on a customer journey for personalised rings: group-session booking, optional design before or during consultation, feasibility decision, estimate, fulfilment, and collection payment. The 16 September stakeholder statements propose location selection, session timing, staff-confirmed additional-participant fees, and staff-created continuation bookings for work in progress; details without group approval remain open rather than becoming commitments.
