### 4.2 Use Cases (UC)

::: {.docx-table width="100%" columns="10%,15%,25%,50%" repeat-header="false"}

|  ID | Use Case                                | Feature                                                                                                                                                                                                                     | Use Case Description                                                                                                                                                                                                                                                  |
| --: | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   1 | Register Account                        | Account Management                                                                                                                                                                                                          | Creates a Member account after successful identity registration via email or SSO.                                                                                                                                                                                     |
|   2 | Sign In                                 | Account Management                                                                                                                                                                                                          | Authenticates the user and resolves the corresponding platform account and role-based permissions.                                                                                                                                                                    |
|   3 | Reset Password                          | Account Management                                                                                                                                                                                                          | Resets a user's password through the configured email-based recovery flow.                                                                                                                                                                                            |
|   4 | Change Password                         | Account Management                                                                                                                                                                                                          | Changes the authenticated user's password and triggers an account-security notification.                                                                                                                                                                              |
|   5 | Manage Personal Profile                 | Account Management                                                                                                                                                                                                          | Allows the authenticated user to view and update permitted personal profile information, including name, phone number, and address.                                                                                                                                   |
|   6 | Manage User Account                     | Account Management                                                                                                                                                                                                          | Creates, views, or updates internal platform staff and user accounts.                                                                                                                                                                                                 |
|   7 | Assign User Role                        | Account Management                                                                                                                                                                                                          | Assigns a business operational role stored in the platform database to an account.                                                                                                                                                                                    |
|   8 | Lock or Unlock User Account             | Account Management                                                                                                                                                                                                          | Changes whether a user account is active or restricted from accessing the platform.                                                                                                                                                                                   |
|   9 | Configure Role-Based Access Control     | Account Management                                                                                                                                                                                                          | Maintains granular permissions and access policies for each platform role.                                                                                                                                                                                            |
|  10 | Browse Product Catalogue                | Product Management                                                                                                                                                                                                          | Displays published, non-deleted products in active categories. Guest or Member searches by keyword, filters by category, price range and purchasable status, sorts the results, and pages through 20 products per page. A product card can open a Quick add box with the same buy panel as the product details to add a size at a branch to the cart, or buy it now, without leaving the list. |
|  11 | View Product Details                    | Product Management                                                                                                                                                                                                          | Displays a published product's images, applied price, available quantity per size and public customer reviews. The Member selects a configured size and a branch that sells the product, in any order, and a quantity up to the available quantity, then adds the item to the shopping cart or uses Buy Now to go straight to checkout. Sizes that are stopped from sale or out of stock remain visible but cannot be selected. |
|  12 | Manage Products                         | Product Management                                                                                                                                                                                                          | Staff or Manager creates draft products with 1–25 fixed sizes (5–29) and system-generated SKUs, updates content and images, manages branch stock (adds selling branches, sets quantity per size at each branch, stops or resumes sale at a branch), stops or resumes the sale of a size, and soft-deletes a product. Staff changes stock only at assigned active branches; at an inactive branch only a Manager can change the quantity. |
|  13 | Import Products from Excel              | Product Management                                                                                                                                                                                                          | Staff or Manager uploads an `.xlsx` template to create multiple draft products. The system validates the whole file and previews row-level errors; products are created only after confirmation, on an all-or-nothing basis, with quantities for the selected branches. Images can then be attached to the new products in one place. |
|  14 | Submit Product or Price Proposal        | Product Management                                                                                                                                                                                                          | Staff submits a new product, and Staff or Manager submits a new price for an existing size, for Manager approval; the submitter's branches at submission are recorded. Each size has at most one pending price proposal at a time.                                    |
|  15 | Approve Product and Price               | Product Management                                                                                                                                                                                                          | The Manager accepts, adjusts, or rejects with a reason a pending product or price proposal, including the Manager's own, and sees who submitted it, from which branches, and who decided it. AI price suggestions are advisory only.                                  |
|  16 | Apply Approved Price                    | Product Management                                                                                                                                                                                                          | Staff or Manager applies an approved price as a separate action. The new price affects only new views and checkouts, not orders or holds already accepted.                                                                                                            |
|  17 | Publish or Unpublish Product            | Product Management                                                                                                                                                                                                          | Manager publishes an approved product that has at least one usable image and an applied price for every size (showing a hidden product again needs at least one priced size), or hides it from the public catalogue while keeping it in product management.                                                                                   |
|  18 | Manage Product Categories               | Product Management                                                                                                                                                                                                          | Staff or Manager finds categories by status and name, creates, renames, activates, or deactivates product categories with system-wide unique names, and reviews the affected products before deactivation.                                                            |
|  19 | Browse Workshop Packages                | Workshop Management                                                                                                                                                                                                         | Displays available workshop packages with pricing, durations, and overview details.                                                                                                                                                                                   |
|  20 | View Workshop Package Details           | Workshop Management                                                                                                                                                                                                         | Displays comprehensive package specifications, included materials, tools, and terms.                                                                                                                                                                                  |
|  21 | Create Workshop Booking                 | Workshop Management                                                                                                                                                                                                         | Selects a workshop package before a schedule/slot and supported ring-design path, enters participant data, and holds a temporary seat.                                                                                                                                |
|  22 | Pay Workshop Deposit                    | Workshop Management                                                                                                                                                                                                         | Pays a 50% deposit of the selected package via VNPay. The booking is confirmed only after a valid payment confirmation.                                                                                                                                               |
|  23 | Look Up Booking Details                 | Workshop Management                                                                                                                                                                                                         | Allows customers to look up a booking by reference code with the contact phone, or through the post-payment email Magic Link, and view details and QR check-in ticket.                                                                                                                                                                      |
|  24 | Check In Participant                    | Workshop Management                                                                                                                                                                                                         | Confirms attendee presence at the workshop via QR code scanning or manual code lookup.                                                                                                                                                                                |
|  25 | Manage Workshop Schedule                | Workshop Management                                                                                                                                                                                                         | Creates, modifies, or cancels workshop calendar sessions, shifts, and branch allocations.                                                                                                                                                                             |
|  26 | Assign Staff to Workshop Slot           | Workshop Management                                                                                                                                                                                                         | Assigns designated instructors or goldsmith staff members to facilitate specific workshop sessions.                                                                                                                                                                   |
|  27 | Configure Workshop Time Slot            | Workshop Management                                                                                                                                                                                                         | Defines the standard daily operating timeframes for workshop sessions.                                                                                                                                                                                                |
|  28 | Configure Workshop Slot Capacity        | Workshop Management                                                                                                                                                                                                         | Sets the maximum seat capacity and participant limits for specific workshop slots.                                                                                                                                                                                    |
|  29 | Configure Supported Materials by Branch | Workshop Management                                                                                                                                                                                                         | Configures the types of jewelry materials and ring options available for selection at each branch location.                                                                                                                                                           |
|  30 | Configure Holiday and Off-Day Exception | Workshop Management                                                                                                                                                                                                         | Sets calendar overrides, closures, and special operating rules for holidays and off-days.                                                                                                                                                                             |
|  31 | Synchronize Workshop Schedule           | Workshop Management                                                                                                                                                                                                         | Exchanges enabled availability updates with Klook while Mland remains the capacity source of truth; Klook must obtain availability/hold before confirmation.                                                                                                          |
|  32 | Synchronize Workshop Booking            | Workshop Management                                                                                                                                                                                                         | Sends enabled Mland confirmed-booking updates to Klook and records Klook bookings confirmed through the Mland availability/hold flow; Klook cancellations are not consumed.                                                                                           |
|  33 | Chat with Basic AI Support              | AI Chatbox Analysis and Suggestion                                                                                                                                                                                          | Answers customer natural language inquiries regarding products, workshops, and store FAQs.                                                                                                                                                                            |
|  34 | Analyze Ring Design from Image (Retired)          | AI Chatbox Analysis and Suggestion                                                                                                                                                                                          | Retired by the Feature-004 member-only rebaseline (2026-11-24): AI no longer assesses design images; Staff or Manager reviews the request by hand.                                                                                                                      |
|  35 | Approve Custom Design Pricing           | AI Chatbox Analysis and Suggestion                                                                                                                                                                                          | Aggregates configured inputs to suggest a price for a new workshop package or retail product. The Manager, not AI, decides the published price; this does not price a custom-manufacturing order.                                                                     |
|  36 | Select Available Ring Model             | Personalized Design and Quote Workflow                                                                                                                                                                                      | Chooses a pre-designed, ready-to-make ring template available in the system catalog.                                                                                                                                                                                  |
|  37 | Configure Workshop Ring                 | Personalized Design and Quote Workflow                                                                                                                                                                                      | A signed-in Member configures the ring to be made in a workshop by assembling compatible system-provided bands, gems, and engravings; a Guest may only browse the public options.                                                                                                                                                    |
|  38 | Chat with Staff Consultant              | Personalized Design and Quote Workflow                                                                                                                                                                                      | Initiates authenticated plain-text consultation polling with Staff or Manager using an owned workshop-ring design or independent Design Request context. Staff is location-scoped, Manager is global, and chat does not approve designs, publish prices, or mutate booking/payment/order state.                                                                                                                                                                 |
|  39 | Submit Custom Design Request             | Personalized Design and Quote Workflow                                                                                                                                                                                      | A signed-in Member submits a description, up to five reference images, and/or a saved Feature-012 ring design as a custom design request for human review. It is not attached to a workshop booking; a Guest is prompted to sign in.                                                                                                                                   |
|  40 | Review Custom Design Request            | Personalized Design and Quote Workflow                                                                                                                                                                                      | Staff or Manager reviews an independent Design Request according to the approved Feature-004 authority policy and records the outcome.                                                                                                                                |
|  41 | View Custom Design Request Decision     | Personalized Design and Quote Workflow                                                                                                                                                                                      | Allows the authorized owner to view the safe recorded outcome of the reviewed independent Design Request.                                                                                                                                                             |
|  42 | View Loyalty Point Balance              | Loyalty and Promotion Management                                                                                                                                                                                            | Displays the Member's own point balance, held points, available points (balance minus held points), and current point value. Points do not expire and there are no membership tiers.                                                                                  |
|  43 | View Loyalty Point History              | Loyalty and Promotion Management                                                                                                                                                                                            | Displays a chronological ledger of earned, redeemed, released, and refunded points, each linked to its retail order or workshop booking.                                                                                                                              |
|  44 | Redeem Loyalty Points                   | Loyalty and Promotion Management                                                                                                                                                                                            | The Member chooses to use points as a non-cash discount on a retail order or workshop booking, from the minimum per use up to the Manager-configured cap. Points combine with an automatic discount, or with a voucher only when it allows points. Points are held on acceptance and deducted after verified payment, or when a valid 0 VND order or booking is accepted. |
|  45 | Manage Automatic Discounts              | Loyalty and Promotion Management                                                                                                                                                                                            | The Manager creates, edits, pauses, or resumes code-free automatic discounts for products or for workshop packages, with no use limits. They always combine with points; when several apply, the largest discount is used. A workshop automatic discount is limited by package only and also applies to Guests booking directly on the website. |
|  46 | Manage Voucher Code                     | Loyalty and Promotion Management                                                                                                                                                                                            | The Manager creates product or workshop vouchers with a system-generated code, scope (product vouchers may be limited to one or more branches), discount, cap (for a percentage; a fixed amount is its own cap), minimum spend, total and per-Member limits, and point-combination option, then edits allowed terms, pauses or resumes them, and tracks usage. |
|  47 | View and Save Vouchers                  | Loyalty and Promotion Management                                                                                                                                                                                            | Guest or Member views public voucher cards and their conditions in the Voucher hub; a signed-in Member saves codes to My vouchers. Fully claimed vouchers stay visible but cannot be saved, and saving does not reserve a use or guarantee eligibility. Product pages show the largest automatic discount as a reduced price and vouchers as labels only; workshop package pages show the price after the largest automatic discount and the best voucher for one ticket, labelled "Price after voucher {code}". |
|  48 | Apply Voucher to Order or Booking       | Loyalty and Promotion Management                                                                                                                                                                                            | The Member applies one voucher or automatic discount to a retail order, based on eligible product lines (and, for a branch-limited voucher, lines at branches in scope) excluding shipping, or one workshop voucher or workshop automatic discount to a booking before the deposit is calculated, discounting only the tickets in scope. A Guest booking directly receives the workshop automatic discount but no voucher or points. Ineligible codes are rejected with a reason. A fee of 0 VND after discounts is accepted. |
|  49 | Earn Loyalty Points                     | Loyalty and Promotion Management                                                                                                                                                                                            | The system awards points once per transaction based on the amount actually paid: after verified full payment of a retail order, or when a workshop booking is completed and fully paid; for a multi-ticket booking, each completed ticket earns its share once. Guest bookings earn no points. |
|  50 | Release or Refund Promotion Benefits    | Loyalty and Promotion Management                                                                                                                                                                                            | The system releases held points and voucher uses when an order, branch order or booking expires or a retail order is cancelled before payment, and refunds the original points, and the voucher use if the voucher has not expired when the cancellation is decided, after a valid or Mland workshop cancellation, per ticket where applicable, exactly once. |
|  51 | Manage Loyalty Point Policy             | Loyalty and Promotion Management                                                                                                                                                                                            | The Manager configures the earning rate, point value, minimum points per use, and point-discount cap. Changes apply only to transactions accepted afterwards.                                                                                                         |
|  52 | Add Product to Cart                     | Order Management and Fulfillment                                                                                                                                                                                            | Adds a selected retail product with chosen variant options (size, engraving) into the cart.                                                                                                                                                                           |
|  53 | Manage Shopping Cart                    | Order Management and Fulfillment                                                                                                                                                                                            | Displays current cart contents, updates item quantities, and removes items from the cart.                                                                                                                                                                             |
|  54 | Checkout Retail Order                   | Order Management and Fulfillment                                                                                                                                                                                            | Revalidates the whole cart, snapshots prices, applies an eligible voucher and/or points, and initiates a 10-minute full-cart payment hold; no partial order is created.                                                                                               |
|  55 | Pay for Retail Order                    | Order Management and Fulfillment                                                                                                                                                                                            | Pays the full retail order through VNPay. A valid signed VNPay confirmation, rather than the browser Return URL, completes the sale and deducts held quantities.                                                                                                      |
|  56 | View Purchase Order History             | Order Management and Fulfillment                                                                                                                                                                                            | Displays a Member's complete chronological list of past and ongoing retail orders.                                                                                                                                                                                    |
|  57 | View Order Details                      | Order Management and Fulfillment                                                                                                                                                                                            | Displays payment and internal fulfilment status for a retail order; it does not provide delivery tracking.                                                                                                                                                            |
|  58 | Review & Confirm Retail Order           | Order Management and Fulfillment                                                                                                                                                                                            | Staff reviews a verified paid retail order, begins its internal preparation, and changes the order status to `Preparing`.                                                                                                                                             |
|  59 | Fulfill Retail Order                    | Order Management and Fulfillment                                                                                                                                                                                            | After verified payment, records the Member's choice of store pickup or GHTK fulfilment, coordinates preparation for that method, and updates the order status accordingly.                                                                                            |
|  60 | Record Customer Pickup                  | Order Management and Fulfillment                                                                                                                                                                                            | Verifies customer identity and changes the status of a ready-for-pickup order to `Picked Up`.                                                                                                                                                                         |
|  61 | Mark Order as Prepared for Carrier      | Order Management and Fulfillment                                                                                                                                                                                            | Records that a prepared retail order was manually handed to GHTK and changes the order status to `Handed to GHTK`; it does not call GHTK APIs or track delivery.                                                                                                      |
|  62 | Configure System Operational Parameters | Administrative Parameter Configuration                                                                                                                                                                                      | Configures approved loyalty and checkout operational values. Custom-order queue parameters are retired from V1.                                                                                                                                                       |
|  63 | Manage Third-Party API Credentials      | Administrative Parameter Configuration                                                                                                                                                                                      | Maintains approved credentials and endpoints for VNPay, Klook, Gemini, Mland SMTP, and cloud storage.                                                                                                                                                                |
|  64 | View Dashboard                          | Administrative Parameter Configuration                                                                                                                                                                                      | Visualizes consolidated business analytics, workshop utilization, retail revenue, branch KPIs and best sellers.                                                                                                                                                                 |
|  65 | View Public Store Reviews and Ratings   | Public Store Information                                                                                                                                                                                                    | Retired from V1. Mland displays only its own approved public review projections for workshop sessions and retail products.                                                                                                                                             |
|  66 | Submit Store Review                     | Public Store Information                                                                                                                                                                                                    | Retired from V1. Mland does not redirect customers to or write reviews to an external review provider.                                                                                                                                                                |
|  67 | Submit Custom Order                     | Custom Manufacturing                                                                                                                                                                                                        | A Member submits a custom-manufacturing order using a reference image or system-supported manual configuration, optional requested deadline, and fulfilment method. AI does not decide the order.                                                                     |
|  68 | Configure Custom Queue                  | Custom Manufacturing                                                                                                                                                                                                        | Retired from V1. No queue minimum deadline, unavailable-date calendar, or maximum queue-size configuration is implemented or exposed.                                                                                                                                 |
|  69 | Pay Custom Order Quote                  | Custom Manufacturing                                                                                                                                                                                                        | Pays the complete Manager-approved custom-order quote through VNPay from the custom-order detail page. No retail cart or deposit is used; the quote/order expires if payment is not verified before its deadline. |
|  70 | View Custom Order                       | Custom Manufacturing                                                                                                                                                                                                        | Allows the Member to view the custom-manufacturing order and its current internal status.                                                                                                                                                                             |
|  71 | Record Custom Payment Outcome           | Custom Manufacturing                                                                                                                                                                                                        | Records the verified full-payment outcome or the expired/cancelled outcome for the active custom-order quote. No final balance is created. |
|  72 | Fulfil Paid Custom Order                | Custom Manufacturing                                                                                                                                                                                                        | Allows production and fulfilment only after the complete quoted amount is verified. |
|  73 | Fulfil Custom Order                     | Custom Manufacturing                                                                                                                                                                                                        | Records Member pickup or Staff's manual handoff of the completed paid item to GHTK.                                                                                                                                                                                   |
|  74 | Browse Public Reviews                   | Review Management                                                                                                                                                                                                           | Guest or Member browses published workshop-session and retail-product reviews and aggregates. Creating or editing a review requires sign-in.                                                                                                                          |
|  75 | Create or Edit Own Review               | Review Management                                                                                                                                                                                                           | A signed-in Member creates or edits a review for an eligible source: a checked-in workshop attendance, or a retail order line that was picked up or delivered. Each source has at most one review.                                                                    |
|  76 | Moderate Review                         | Review Management                                                                                                                                                                                                           | Staff hides a published review; Manager hides, removes, or replies to one. Admin has technical/audit access only.                                                                                                                                                     |

:::

> **Feature-004 replacement baseline (2026-11-24):** Feature-004 is now a member-only custom design request with human review; the legacy AI use cases in this table (including Analyze Ring Design from Image) are superseded. Use cases 33 (Chat with Basic AI Support) and 35 (Approve Custom Design Pricing) are pending confirmation because the Feature-004 spec no longer lists them. Current behavior is documented in the Feature-004 spec and must be used for implementation.
