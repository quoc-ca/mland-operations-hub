## 1. Context and Main Business Flow

The Context Diagram illustrates the system boundaries of the platform and its data interactions with external actors and third-party systems. The system interacts directly with five primary user roles: Guest, who browses products, workshops, and reviews, registers accounts, and submits custom AI design or workshop requests; Member, who manages personal profiles, loyalty points, cart orders, custom AI ring design estimations, payments, and product/service feedback; Staff, who processes custom design quotes, updates product catalogs, handles orders, and manages workshop check-ins; Manager, who reviews analytics dashboards, manages workshop schedules, configures promotions, and approves high-value design quotes; and Admin, who oversees system parameters, security settings, user accounts, and third-party API integrations. Furthermore, the platform integrates seamlessly with several external services and secondary actors: SSO Providers (Google/Facebook) for authentication; Mail Gateway for sending security codes, notifications, and QR tickets; AI Support / AI API for automated chatbot responses and image recognition for custom design valuations; Payment Gateway for online transactions and deposit handling; Google Maps API for synchronizing customer reviews and ratings; Cloud Storage Service for storing media assets; Delivery Providers for logistics management; and an External Registration System for managing external user registration data.
