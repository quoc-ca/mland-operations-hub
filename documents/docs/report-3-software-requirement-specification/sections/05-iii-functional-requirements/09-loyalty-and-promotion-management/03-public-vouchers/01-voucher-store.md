#### 9.3.1 Voucher Store

![](assets/screens/88-voucher-store.png)

This screen allows visitors and Members to:

- Browse active public vouchers, all together or by retail-product or workshop scope.
- See each voucher's discount, minimum order value, branch restriction, code, expiry date and whether it can be combined with points.
- As a Member, save a voucher to My Saved Vouchers; a visitor is asked to sign in first.
- Open a voucher's conditions.

Automatic discounts are not listed here; they appear on product and workshop pages.

| Field Name | Description |
| --- | --- |
| Scope tabs | Tất cả, Sản phẩm or Workshop. |
| Voucher của tôi | Opens My Saved Vouchers. |
| Voucher ticket | Scope label, discount (with maximum for a percentage), minimum order value, branch restriction, programme name, code, expiry date (HSD) and Dùng cùng điểm / Không dùng cùng điểm. Exhausted or fully used vouchers are marked. |
| Lưu voucher / Đăng nhập để lưu | Saves the voucher for the Member, or sends a visitor to sign in; a saved voucher shows "Đã lưu". |
| Điều kiện | Opens Voucher Details. |
| Footnote | A ticket is for reference only; whether the voucher applies is checked when the order is placed. |
