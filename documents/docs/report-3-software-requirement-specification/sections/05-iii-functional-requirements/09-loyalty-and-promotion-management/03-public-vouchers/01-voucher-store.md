#### 9.3.1 Voucher Store

![](assets/screens/10-voucher-store.png)

This screen, titled **Voucher hub**, allows visitors and Members to:

- Browse the active vouchers that must be saved before use, all together or by retail-product or workshop scope.
- See each voucher's discount, minimum order value, branch restriction, code, expiry date and whether it can be combined with points.
- As a Member, save a voucher to My Saved Vouchers, which claims one of its uses; a visitor is asked to sign in first.
- Open a voucher's conditions.

Public vouchers need no saving and are not listed here: they show on product and workshop pages and are suggested at checkout. Automatic discounts are not listed either; they appear on product and workshop pages.

| Field Name | Description |
| --- | --- |
| Scope tabs | All, Products or Workshops. |
| My vouchers | Opens My Saved Vouchers. |
| Voucher ticket | Scope label, discount (with maximum for a percentage), minimum order value, branch restriction ("Only at: {branches}"), programme name, code, expiry date, Combines with points / No points with it, and "Save to use". A voucher with no use left to claim is marked "All claimed"; a voucher whose use the Member has used is marked "You used all your uses". |
| Save voucher / Sign in to save | Saves the voucher for the Member and claims one use, or sends a visitor to sign in; a saved voucher shows "Saved." with a link to My vouchers. A refused save shows "All claimed" or "You have used your use of this code"; a signed-in non-Member sees "Only members can save vouchers." |
| Conditions | Opens Voucher Details. |
| Empty state | "There are no vouchers to save right now." |
| Footnote | Offer cards are for information; whether a voucher applies is checked when the order is placed. |
