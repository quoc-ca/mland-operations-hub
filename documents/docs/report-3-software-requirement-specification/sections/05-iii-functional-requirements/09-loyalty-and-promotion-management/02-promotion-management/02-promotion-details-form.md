#### 9.2.2 Promotion Form

![](assets/screens/68-promotion-form.png)

This screen allows Managers to:

- Create a voucher or an automatic discount for retail products or workshops.
- Set the programme name, validity window and discount, by percentage with a maximum or by a fixed amount, plus a minimum eligible value.
- For a voucher, use the system-generated unique code, allow or forbid combining it with loyalty points, set total and per-Member usage limits, and choose its distribution: Public or Must be saved.
- Choose the programme's targets: branches and products or individual sizes for retail, or packages, branches and sessions for a workshop voucher, or one or more packages for a workshop automatic discount.

Existing programmes are edited from Promotion Details using the same fields; the kind, scope, voucher code, targets and distribution cannot change after creation.

| Field Name | Description |
| --- | --- |
| Kind | Voucher or Automatic discount. |
| Scope | Products or Workshops. |
| Programme name | Required text input of up to 200 characters. |
| Voucher code | Read-only unique code generated by the system; **Generate another code** generates another. Voucher only. |
| Starts / Ends | Date plus hour and minute, with the resulting date-time shown below; a new programme is prefilled with a 30-day window starting at the next quarter hour. |
| Discount type | Percentage or Fixed amount. |
| Percentage / amount | "Percentage (%)" (above 0 and up to 100, at most 6 decimals) with a required "Maximum discount (₫)", or "Amount (₫)"; amounts are positive whole numbers, and a fixed amount has no maximum discount field. |
| Minimum amount (₫) | Minimum eligible amount; 0 means no minimum. |
| Allow points together with this voucher | Voucher only: whether loyalty points can be used together with this voucher. An automatic discount always combines with points. |
| Usage limits | Voucher only: total uses and uses per Member, both positive whole numbers; uses per Member is fixed at 1 for a voucher that must be saved. |
| Distribution | Voucher only: "Public — no saving needed" (default; customers can use it at checkout without saving it) or "Must be saved — saving claims a use" (shown in the Voucher Store with a Save button; each save claims one use of the total; only members who saved it can use it; one use per member). |
| Targets | Retail voucher: All branches or Only some branches, and whole products or individual sizes; a product automatic discount applies at every branch. Workshop voucher: package, branch and session, each "All" or exactly one item. Workshop automatic discount: one or more packages only, with no branch, date or session limit. |
| Find a product | Retail only: searches by product name, product number or SKU, with the filter All / Public / Not public yet or hidden; **Choose all on this page** / **Clear all on this page** select or clear the products shown. |
| Create programme / Cancel | **Create programme** validates the complete configuration and creates the programme, then opens its details; **Cancel** returns to Promotion List. |
| Unanswered create | If a create got no answer, opening the form again offers **Send that same request again**, **Dismiss** and **See the programme list**. |
