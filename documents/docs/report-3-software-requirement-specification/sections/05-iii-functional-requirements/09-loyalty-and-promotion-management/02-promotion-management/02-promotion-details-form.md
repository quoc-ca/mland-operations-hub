#### 9.2.2 Promotion Details / Form

![Promotion Details / Form mockup](assets/screens/69-promotion-details-form.png)

This screen allows Managers to:

- Create or edit a promotion's name, approved benefit type/value and validity period.
- Configure supported eligibility, branch applicability, limits and voucher constraints where applicable.
- Save or change activation only after validating the complete promotion.
- Preserve existing discount history when retiring or changing future eligibility.

| Field Name | Description |
| --- | --- |
| Campaign / benefit / period / state | Read-only promotion overview; sample rates and point multipliers are illustrative, not approved benefit policies. |
| Campaign name | Text input for a promotion. |
| Type / value | Configured benefit selection and amount; validate against approved discount rules rather than copying example percentages. |
| Period | Date/time validity window. |
| Create / Save Promotion | Manager actions that validate the complete configuration before save or activation. |
