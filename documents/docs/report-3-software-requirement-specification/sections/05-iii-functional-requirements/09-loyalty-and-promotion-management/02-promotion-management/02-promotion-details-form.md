#### 9.2.2 Promotion Form

![](assets/screens/69-promotion-details-form.png)

This screen allows Managers to:

- Create a voucher or an automatic discount for retail products or workshops.
- Set the programme name, validity window and discount, by percentage with a maximum or by a fixed amount, plus a minimum eligible value.
- For a voucher, use the system-generated unique code, allow or forbid combining it with loyalty points, and set total and per-Member usage limits.
- Choose the programme's targets: branches and products or individual sizes for retail, or packages, branches, dates and sessions for workshops.

Existing programmes are edited from Promotion Details using the same fields; the kind, scope and voucher code cannot change after creation.

| Field Name | Description |
| --- | --- |
| Kind (Loại) | Voucher or Giảm giá tự động. |
| Scope (Phạm vi) | Sản phẩm or Workshop. |
| Programme name (Tên chương trình) | Required text input. |
| Voucher code (Mã voucher) | Read-only unique code generated by the system; **Sinh mã khác** generates another. Voucher only. |
| Start / End (Bắt đầu / Kết thúc) | Date plus hour and minute, with the resulting date-time shown below. |
| Discount method (Cách giảm) | Theo phần trăm or Số tiền cố định. |
| Percentage / amount | "Phần trăm giảm (%)" with "Giảm tối đa (₫)", or "Số tiền giảm (₫)". |
| Minimum value (Giá trị tối thiểu (₫)) | Minimum eligible amount; 0 means no minimum. |
| Allow points (Cho phép dùng điểm cùng voucher này) | Voucher only: whether loyalty points can be used together with this voucher. |
| Usage limits (Giới hạn lượt dùng) | Voucher only: total uses and uses per Member. |
| Targets (Đối tượng áp dụng) | Retail: all or selected branches, and whole products or individual sizes. Workshop: packages, branches, dates and sessions, each with an "all" option. |
| Tạo chương trình / Hủy | Validates the complete configuration and creates the programme, then opens its details. |
