#### 9.2.3 Promotion Details

![](assets/screens/91-promotion-details.png)

This screen allows Managers to:

- View a programme's kind, voucher code, scope, state, discount and conditions.
- Edit the programme's name, validity window, discount, minimum value, usage limits and points setting.
- Pause or resume the programme after confirmation.
- Follow the programme's usage and the total amount discounted.

| Field Name | Description |
| --- | --- |
| Header | Kind (Voucher or Giảm giá tự động), voucher code, scope badge and state badge (Đang bật or Tạm dừng). |
| Discount (Mức giảm) | Fixed amount, or percentage with its maximum. |
| Conditions | Validity window, minimum value, whether points can be combined, branches or targets, total uses and uses per Member; a warning appears when targeted products can no longer be bought. |
| Version line | Version, edit count and creation time. |
| Sửa | Opens inline editing of the programme with **Lưu** / **Hủy**. |
| Tạm dừng / Mở lại | Pauses or resumes the programme after confirmation; a paused programme is not offered to new orders. |
| Usage (Tình hình sử dụng) | Voucher: used / total, currently held, uses per Member and total discounted. Automatic discount: orders that received it and total discounted. |
| Quay lại | Returns to Promotion List. |
