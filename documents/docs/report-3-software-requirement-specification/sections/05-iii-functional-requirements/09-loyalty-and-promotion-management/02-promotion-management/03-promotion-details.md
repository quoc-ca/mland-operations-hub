#### 9.2.3 Promotion Details

![](assets/screens/91-promotion-details.png)

This screen allows Managers to:

- View a programme's kind, voucher code, scope, state, distribution, discount and conditions.
- Edit the programme's name, validity window, discount, minimum value, usage limits and points setting.
- Pause or resume the programme after confirmation.
- Follow the programme's usage and the total amount discounted.

| Field Name | Description |
| --- | --- |
| Header | Kind (Voucher or Automatic discount), voucher code, scope badge and status badge (Enabled or Paused). |
| Discount | Fixed amount, or percentage with its maximum. |
| Conditions | Validity window, minimum value, whether points can be combined, branches or targets, total uses and uses per Member; a warning appears when targeted products can no longer be bought or a targeted branch is no longer active. |
| Distribution | Voucher only, read-only: Public or Must be saved. |
| Version line | Version, revision and creation time. |
| Edit | Opens inline editing of the programme with **Save** / **Cancel**; kind, scope, voucher code and targets cannot change, and a limit cannot be lower than the uses consumed, held or, for a voucher that must be saved, saved. |
| Pause / Resume | Pauses or resumes the programme after confirmation; a paused programme is not offered to new orders. |
| Usage | Voucher: used / total, held, saved but not used yet (voucher that must be saved) and total discount given. Automatic discount: accepted orders and total discount given. |
| Back | Returns to Promotion List. |
