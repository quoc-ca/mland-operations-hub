#### 9.2.4 Point Policy

![](assets/screens/92-point-policy.png)

This screen allows Managers to:

- View the loyalty-point policy currently in force and its version.
- Change how points are earned and spent; the change applies only to transactions accepted after saving.

| Field Name | Description |
| --- | --- |
| Amount to earn 1 point (Số tiền để tích 1 điểm (₫)) | Whole-VND amount that earns one point. |
| Value of 1 point (Giá trị 1 điểm (₫)) | Whole-VND value of one point when spent. |
| Minimum points per use (Số điểm tối thiểu mỗi lần dùng) | Smallest number of points that can be spent at once. |
| Maximum share paid by points (Tối đa % giá trị được trả bằng điểm) | Highest percentage of an order's value that points may cover. |
| Rounding (Làm tròn) | Read-only rounding rule (round down). |
| Version (Phiên bản) | Read-only policy version and effective time. |
| Sửa | Opens the policy form with the four editable values and **Lưu** / **Hủy**; existing orders and history keep the policy they were accepted under. |
