#### 9.1.3 My Saved Vouchers

![](assets/screens/90-my-saved-vouchers.png)

This screen allows Members to:

- Review the vouchers they have saved, filtered by scope and split into still valid and expired or unusable.
- See each voucher's availability, code, discount and full conditions.
- Go to products or workshops to use a voucher, or find more vouchers in the Voucher Store.

Saving a public voucher does not reserve a use; a use is held only when an order is placed. Saving a voucher that must be saved claims one use for the Member, and that voucher stays usable for the Member even when no use is left for others.

| Field Name | Description |
| --- | --- |
| Scope filter | All, Products or Workshops, as in the Voucher Store. |
| Tabs | Valid (usable or not started yet) and Expired / Unusable, each with a count. |
| Find more vouchers | Opens Voucher Store. |
| Voucher card | Scope badge (Products or Workshops), availability (Usable, Paused, Not started yet, Expired, No product or package left, No uses left or You have used all your uses), programme name, code and discount. |
| Conditions | Validity window, minimum value, whether points can be combined, branch, total uses and uses per Member. |
| Saved time | "Saved {date-time}": when the Member saved the voucher. |
| Use now | Shown for a usable voucher; opens the product catalogue or workshop list according to the voucher's scope. |
| Empty state | "You have not saved any voucher." with **See offers**. |
