#### 9.1.3 My Saved Vouchers

![](assets/screens/90-my-saved-vouchers.png)

This screen allows Members to:

- Review the vouchers they have saved, split into still valid and expired or unusable.
- See each voucher's availability, code, discount and full conditions.
- Go to products or workshops to use a voucher, or find more vouchers in the Voucher Store.

Saving a voucher does not reserve a use; a use is held only when an order is placed.

| Field Name | Description |
| --- | --- |
| Tabs | Còn hiệu lực and Hết hạn / Không dùng được, each with a count. |
| Tìm thêm voucher | Opens Voucher Store. |
| Voucher card | Scope badge (Workshop or Sản phẩm), availability (for example Dùng được, Đang tạm dừng, Chưa đến thời gian or Hết hạn), programme name, code and discount. |
| Conditions | Validity window, minimum value, whether points can be combined, branch, total uses and uses per Member. |
| Saved time (Đã lưu lúc) | When the Member saved the voucher. |
| Dùng ngay | Opens the product catalogue or workshop list according to the voucher's scope. |
| Empty state | "Bạn chưa lưu voucher nào." with **Xem ưu đãi**. |
