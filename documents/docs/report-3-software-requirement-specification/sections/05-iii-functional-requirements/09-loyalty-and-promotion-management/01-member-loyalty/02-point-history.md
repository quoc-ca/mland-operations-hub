#### 9.1.2 Point History

![](assets/screens/36-point-history.png)

Point history is the **Point history** section of the My Loyalty page. It allows Members to:

- Review their own point transactions, newest first.
- See each transaction's type and source order or workshop booking.
- Distinguish balance changes from changes to held points.
- Load further transactions.

| Field Name | Description |
| --- | --- |
| When | Date and time the transaction was recorded. |
| Type | Points earned, Points held, Points used, Hold released or Points restored. |
| Source | The order (Order #ref) or workshop booking (Workshop #ref) that caused the transaction. |
| Balance | Signed change to the point balance. |
| Held | Signed change to the held points. |
| Load more | Loads older transactions; with no transactions the section shows "You have no point transactions yet." |
