#### 5.1.1 Ring Design Entry

![](assets/screens/live/16-ring-design-entry.png)

This screen allows Guests and Members to:

- Open the independent workshop-ring designer for a workshop package; two short addresses open it for the default couple silver package.
- Read that the ring configuration applies only to workshop crafting and that its estimate does not change the package price or deposit.
- Start from a model suggested for the package, which opens Ring Model Selection.
- Start from a blank ring band, which opens Ring Configuration in blank mode.

The page needs no sign-in. A Guest also sees a notice with a sign-in link and may browse a local preview; saving a design requires sign-in.

**Field Description**

| Field Name | Description |
| --- | --- |
| Title and subtitle | "Workshop Ring Design Configuration" with "Craft and personalize bespoke ring specifications for your upcoming workshop experience." |
| Workshop-only notice | Information banner: "Ring configuration applies exclusively to Workshop crafting. Advisory estimate does not alter the package price or the deposit." |
| Guest notice | Shown only to a Guest: "You are browsing as a Guest. You can preview ring models; please sign in to store the design." The sign-in link returns to this page (no English label in the app). |
| "Choose a Starting Point" | Heading of the two starting-point cards. |
| "Package Suggested Models" card | Starts from an artisan-approved standard template for the package; the card or its **Select this model** button opens Ring Model Selection. |
| "Start from Blank Design" card | Starts from a plain ring band with every dimension customizable; the card or its **Start Configuring** button opens Ring Configuration in blank mode. |
