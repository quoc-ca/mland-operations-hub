#### 5.1.2 Ring Model Selection

![](assets/screens/live/17-ring-model-selection.png)

This screen allows Guests and Members to:

- Browse the published ring models that the server supplies for the workshop package.
- See each model's image, material, name, description and estimated difficulty.
- Select a model, which opens Ring Configuration pre-filled with that model's options.
- Start from a blank ring instead when the package has no suggested models.
- Go back to Ring Design Entry.

The page needs no sign-in. No design is created until a signed-in Member saves it in Ring Configuration.

**Field Description**

| Field Name | Description |
| --- | --- |
| Title and subtitle | "Package Suggested Models" with "Begin from an artisan-approved standard template curated for this package." |
| **← Back to Models** | Returns to Ring Design Entry. |
| Loading / error | "Loading design models..." while loading; the server message or "Could not load the design models." when loading fails. |
| Empty state | "This workshop package has no suggested models yet. You can start from a blank design." with a **Start from Blank Design** button. |
| Model card | Image (when available), material tag ("Sterling Silver 925", "Copper" or "Stainless steel"), model name and description. |
| Estimated difficulty | "Estimated difficulty: {score} ({level})", shown when the model has a score; the level is Easy, Medium, Hard or Very hard. |
| **Select this model** | Opens Ring Configuration in model mode for the chosen model; clicking the card does the same. |
