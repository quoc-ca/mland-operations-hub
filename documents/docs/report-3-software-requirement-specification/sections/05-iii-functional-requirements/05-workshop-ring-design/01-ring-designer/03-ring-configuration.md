#### 5.1.3 Ring Configuration

![](assets/screens/live/18-ring-configuration.png)

This screen allows a Member to configure and save a design; a Guest can only change a local preview:

- Configure a ring from a chosen model, from a blank band or from an existing saved design (edit mode), using the options the server supplies for the package.
- Choose material, band shape, ring size, thickness and band width, gemstones, decorative attachments and engraving.
- See a live preview with top and side views, and a summary with the estimated weight.
- Save with **Save & Evaluate** or **Save & View in Saved Designs**.

Both save buttons stay disabled while the configuration fails validation. The first save creates the design; each save stores a new version. A Guest pressing either button is sent to sign-in and nothing is saved.

On the screen, they can also:

- Open the ring size guide, measure the finger and pick a size from its conversion table.
- Upload a finger-measurement photo to compare with the size table; the photo is not saved.

**Field Description**

| Field Name | Description |
| --- | --- |
| Title and subtitle | "Workshop Ring Design Configuration" with its subtitle. |
| Advisory banner | "Price estimate and difficulty score are advisory. Official payable amount adheres to your chosen workshop package." |
| Guest notice | Shown only to a Guest: "You are previewing as a Guest. Please sign in to save or evaluate this design." (no English label in the app). |
| 1. Ring Material | Material cards from the server with unit price; exactly one is selected. A material without a published difficulty score is disabled with "Difficulty score pending Admin publication". |
| 2. Band Shape & Sizing | Required band shape cards with any added price, then ring size pills from 6 (46 mm) to 29 (69 mm) showing circumference and inner diameter. |
| Ring Size Guide & Chart | Opens a dialog with a size chart image, two measuring methods, a quick-pick size table and an optional finger-photo upload. The dialog texts have no English label in the app. |
| 3. Gemstone & Components | Gemstone cards with per-stone price, a per-stone maximum and **+ Add stone**, **−** and **+** controls. At most 10 stones in total ("Total stones: {count}/10"); stones are positioned by dragging on the top view. |
| 4. Decorative Attachments | Optional attachment cards, such as milgrain edges or brushed finishing, each with its added price and "✓ Selected" when chosen. |
| 5. Custom Engraving & Laser Image | Check box "Standard Text & Symbol Engraving (+80,000 VND flat fee)": up to 2 text or symbol placements of 50 characters each, inner or outer band, with quick symbols. Laser image upload: up to 2 images at 100,000 VND each, cropped to a 160 × 160 px black-and-white frame with contrast and sharpness. Outer engraving is disabled when stones sit on the outer band. |
| Surface texture warning | Shown for textured bands; recommends inner-band engraving. |
| Preview | Draft status badge, "Advisory Estimate" badge, top view, and side view with thickness (1.0–3.0 mm) and width (1.5–6.0 mm) controls in 0.1 mm steps. |
| Unsaved-changes notice | "You have unsaved changes. Please click "Save & Evaluate" to create a new authoritative version." |
| Summary | Material, band shape, size, thickness, width, estimated weight (standard quota ≤ 3.0 g; excess weight shows its added cost), gemstones, engraving (+80,000 VND) and laser images (+100,000 VND each). |
| **Save & Evaluate** | Saves the design, then opens Design Evaluation; shows "Saving & Evaluating..." while saving and the error message if saving fails. |
| **Save & View in Saved Designs** | Saves the design in the same way, then opens My Ring Designs. |
