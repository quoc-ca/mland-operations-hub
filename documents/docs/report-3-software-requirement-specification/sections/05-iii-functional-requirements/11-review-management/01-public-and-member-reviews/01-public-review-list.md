#### 11.1.1 Public Review List

![](assets/screens/live/28-public-review-list.png)

This screen allows Guests, Members, Staff and Managers to:

- Read the public workshop and retail product reviews of Mland, newest first by default.
- See the average rating and the review count, both calculated from public reviews only; hidden and removed reviews never appear and are not counted.
- Sort the list and filter it by review target and star rating.
- Read the reviews of one workshop package across all its sessions when the page is opened from that package.
- Open a review's details.

The screen is public. A signed-in Member opening the Reviews menu gets Eligible Review Sources instead, except when the list is filtered by a package. A Guest can select **Write review** to sign in; Staff and Managers get no write entry point.

Reviewer names are partly masked or replaced by "Mland Customer"; email, phone and transaction data are never shown.

**Field Description**

| Field Name | Description |
| --- | --- |
| Title | "Customer reviews"; with a package filter, "Reviews of package: {package name}" and the link "See reviews of all packages" back to the full list. |
| Rating summary | Average rating with one decimal, star display and the number of public reviews. |
| Write review | For a signed-out visitor it opens sign-in and returns to this list; for a signed-in Member on a package list it opens Eligible Review Sources. |
| Sort by | Options: Newest, Highest Rating, Lowest Rating. Default: Newest. Reviews with the same rating are ordered newest first. |
| Target type | Options: All Experiences, Workshop Reviews, Product Reviews. Default: All Experiences. |
| Rating (1–5) | Options: All, or one star value from 5 to 1. Default: All. |
| Shown count | Number of reviews loaded out of the total matching reviews. |
| Review card | Stars, status badge, masked name, review text, up to 3 photo thumbnails (full size opens on click), the current Manager reply ("Official Response from Mland Management"), "Package: {name}" for a workshop review, the target ("Workshop session" or "Retail product"), the creation time and **Open**. |
| Show more reviews | Loads the next page of reviews and appends it; hidden when no more pages remain. |
| Empty message | "No public reviews yet." when no public review matches. |
