#### 11.2.1 Review Moderation Queue

![](assets/screens/live/59-review-moderation-queue.png)

This screen allows Staff and Managers to:

- See the reviews they can moderate, including public, hidden and removed reviews.
- Filter the reviews by status.
- See their own role and a notice of what each role may do.
- Open a review in Review Moderation Details.

Only Staff and Managers can open the screen; other signed-in roles are routed to the not-found page. The page title comes from the operations shell tab **Reviews**.

**Field Description**

| Field Name | Description |
| --- | --- |
| Back to Home | Returns to the home page. |
| Subtitle | "Staff and Manager actions follow the approved permissions." |
| Role notice | "Note: Staff can only Hide reviews. Managers have full authority to Hide, Remove, Restore and Reply." |
| Current role: | "Manager (MANAGER)" or "Staff (STAFF)". |
| Filter status | Options: All, PUBLIC, HIDDEN, REMOVED. Default: All. Applied to the loaded list at once. |
| Shown count | Number of reviews matching the filter out of the loaded reviews; only the 20 newest reviews are loaded, with no paging. |
| Review card | Stars, status badge, masked name, text, photos, current Manager reply, package, target type and creation time. |
| Open | Opens Review Moderation Details for the review. |
| Empty message | "No public reviews yet." when no review matches the filter. |
