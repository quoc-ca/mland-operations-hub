#### 7.4.2 Carrier Statistics

![](assets/screens/98-carrier-statistics.png)

This screen allows the Carrier to:

- Choose Ngày, Tuần, Tháng or Năm and a date; the period is calculated in Vietnam time.
- View shipments received, picked up and delivered, the average time from pickup to delivery and the shipping fees of delivered shipments.
- View a trend chart over the period and a table per pickup branch.
- Access this page (/carrier/stats) only with an active GHTK partner account (role CARRIER).

| Field Name | Description |
| --- | --- |
| Kỳ / Ngày | Period type (Ngày, Tuần, Tháng, Năm) and a date no later than today; picking a date switches the period to Ngày. |
| Vận đơn tiếp nhận | Shipments created in the period. |
| Đã lấy hàng | Shipments picked up in the period, with Đang chờ lấy: the count still waiting for pickup. |
| Giao thành công | Shipments delivered in the period, with Đang giao: the count still on the way. |
| Thời gian giao trung bình | Average time from pickup to delivery. |
| Cước vận chuyển | Shipping fees of the shipments delivered in the period. |
| Trend chart | Tiếp nhận, Lấy hàng and Giao thành công per hour, day or month of the period. |
| Theo chi nhánh lấy hàng | Per pickup branch: Tiếp nhận, Giao thành công and Cước vận chuyển; Chưa có vận đơn trong kỳ này when empty. No failed delivery or return figures. |
