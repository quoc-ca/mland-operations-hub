#### 7.3.3 GHTK Partner Orders

This screen allows the GHTK partner to:

- Browse the GHTK shipments of every Mland branch, newest first, by status Đã tiếp nhận, Đang lấy hàng, Đang giao hàng and Đã giao hàng, and search by tracking number, order code, recipient name or phone.
- See where to collect, whom to deliver to, the item count and the shipping fee.
- Press Đã lấy hàng after collecting a packed parcel and Giao thành công after delivering it.
- Access this portal only with an active GHTK partner account (role CARRIER).

| Field Name | Description |
| --- | --- |
| Mã vận đơn / Mã đơn | Platform tracking number and the Mland order code. |
| Trạng thái vận đơn | Đã tiếp nhận (shop still preparing, no need to come yet), Đang lấy hàng (shop finished packing), Đang giao hàng, Đã giao hàng. |
| Lấy hàng tại | Pickup branch. |
| Giao đến | Recipient name, phone and address. |
| Items / Cước vận chuyển | Item count and shipping fee only; no product prices, vouchers, points or Member account data. |
| Times | Shop chuẩn bị xong, Đã lấy hàng and Giao thành công times. |
| Đã lấy hàng / Giao thành công | Records the courier step once after state checks; a stale list is refused and must be reloaded. |
| Simulation notice | Mô phỏng · không phải hệ thống GHTK thật. |
