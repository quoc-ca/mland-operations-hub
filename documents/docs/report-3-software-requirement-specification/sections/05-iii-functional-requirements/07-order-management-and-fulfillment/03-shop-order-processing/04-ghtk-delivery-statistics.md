#### 7.3.4 GHTK Delivery Statistics

This screen allows the GHTK partner to:

- Choose Ngày, Tuần, Tháng or Năm in Vietnam time and a date.
- View shipments received, picked up and delivered, the average time from pickup to delivery and the shipping fees of delivered shipments.
- View a trend chart over the period and a table per pickup branch.
- Access this page only with an active GHTK partner account (role CARRIER).
- Read every label in Vietnamese or English with the VI/EN switch.

| Field Name | Description |
| --- | --- |
| Loại kỳ / Chọn ngày | Period type and date; the period is calculated in Vietnam time. |
| Vận đơn tiếp nhận | Shipments created in the period. |
| Đã lấy hàng / Giao thành công | Shipments picked up and delivered in the period. |
| Thời gian giao trung bình | Average time from pickup to delivery. |
| Cước vận chuyển | Shipping fees of the shipments delivered in the period. |
| Trend chart | Received, picked up and delivered shipments per hour, day or month. |
| Theo chi nhánh lấy hàng | The same figures per pickup branch; no failed delivery or return figures. |
