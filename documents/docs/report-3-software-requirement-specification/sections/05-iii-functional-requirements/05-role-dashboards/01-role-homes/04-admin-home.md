#### 5.1.4 Admin Home

{{r3-05-admin-home width=100% align=center}}

**Description:** Displays the system account directory as the Admin landing page after sign-in and allows Admins to navigate across account, role, ring difficulty, and notification administration modules.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Top navigation bar | Provides quick access to **Home**, **System** (notification templates, delivery logs, ring difficulty), language switcher (`VI`/`EN`), **Profile**, and **Sign out**. |
| Admin navigation tabs | Switches between **Accounts** and **Roles** views. |
| + Create internal account | Opens New Internal Account to provision Staff, Manager, or Carrier accounts. |
| Search & filters | Filters accounts by email/name, role, and status. |
| Account table | Lists system accounts with ID, sign-in email, role, status, last updated timestamp, and **Details**. |

:::
