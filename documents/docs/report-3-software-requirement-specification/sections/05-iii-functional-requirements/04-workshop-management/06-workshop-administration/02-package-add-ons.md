#### 4.6.2 Package Add-ons

![](assets/screens/live/76-package-add-ons.png)

This screen allows Managers to:

- Choose a workshop package and a location to see the add-ons configured for that pair.
- Create an add-on as a draft with a description and a price in VND.
- Edit an add-on that is not retired.
- Activate a draft add-on so customers can choose it, or stop selling an active one.

Customers can only choose an add-on while it is **Active**. Staff can open the page, but it is not in their menu; changes are checked by the server.

**Field Description**

| Field Name | Description |
| --- | --- |
| **Workshop package *** | Required package of the add-on scope, listed published first, each with its state. Default: the first published package, or the last package chosen in this browser tab. |
| **Location *** | Required location of the add-on scope. Default: the first location, or the last location chosen in this browser tab. |
| **New add-on (draft)** / **Edit add-on** | Form title, with a note that prices are in VND and customers can choose an add-on only while it is **Active**. |
| **Add-on description *** | Required description shown for the add-on, up to 200 characters, for example engraving. |
| **Price (VND) *** | Required price in VND. |
| **Create draft** / **Save changes** | Creates a draft add-on, or saves the add-on being edited; **Cancel editing** leaves the edit. |
| **Configured add-ons** | Columns **Add-on description**, **Reference**, **Price**, **Status** and **Actions**, with the number of entries for the chosen package and location. |
| **Status** | **Draft**, **Active** or **Retired**. |
| **Edit** / **Activate** / **Stop selling** | **Edit** is disabled for a retired add-on; **Activate** appears on a draft and **Stop selling** on an active add-on. |
| Empty states | "Select a workshop package and a location above." or "No add-ons in this scope yet." |
