#### 4.1.1 Workshop Package List

![](assets/screens/live/13-workshop-package-list.png)

This screen allows Guests and Members to:

- Browse the published workshop packages as cards, nine cards per page.
- Compare each package's number of sessions, tickets per booking and price per person.
- See the price per ticket after the best automatic discount and the best usable voucher, with the offer badges.
- Open a package's details at its session choice with **Choose a session & book**.

On the screen, they can also:

- Open the ring designer before the class with **Configure your ring now →**.
- Move between pages of package cards.
- Read the latest public workshop reviews at the bottom of the page and open the full review list.

Browsing the list never holds a seat. The voucher price is display only; the booking quote decides the amount to pay.

**Field Description**

| Field Name | Description |
| --- | --- |
| Page header | Eyebrow **WORKSHOPS AT MLAND**, title **Discover the Workshop packages** and a short introduction. |
| Design prompt | **Want to choose the ring shape, material or design your own model before the class?** with **Configure your ring now →**, which opens the ring designer. |
| Package card | Illustration, package name and description. |
| Sessions chip | **⏱ {count} session(s)**: the number of sessions one booking of this package needs. |
| Tickets chip | **{count} ticket(s)** or **{min}–{max} tickets**: the number of tickets allowed in one booking. |
| Same branch chip | **📍 Same branch**; shown only for a package with several sessions that must all be at one branch. |
| Price | Price per person (**/ person**). When an offer applies, the reduced price shows with the public price struck through. The reduction counts the best automatic discount and the best usable voucher. A voucher limited to sessions or dates is never counted. Otherwise the public price is shown. |
| Voucher price tag | **Price after voucher {code}**, with **· at {branches}** for a voucher limited to branches. A visitor who is not signed in also sees **Members only**. |
| Offer badges | The best automatic discount (**{value} off**) or, when none applies, one discount for bigger orders (**{value} off orders from {minimum}**). Up to two vouchers follow (**Code: {value} off** or **Save code: {value} off**, with any minimum). A visitor who is not signed in also sees **Sign in to use a code**. |
| Choose a session & book | Opens Workshop Package Details and scrolls to the session choice. |
| Load and empty states | **Loading the workshop packages...** while loading. On error, the error text with **Try again**. With no package, **No workshop package is on sale right now.** |
| Pager | Moves between pages of package cards. |
| Workshop reviews | Eyebrow **WORKSHOP REVIEWS** and **What customers say about MLAND workshops**: the average rating, the number of public reviews and up to three recent reviews with the package name. **View all {count} reviews** appears when there are more; **No public reviews yet.** when there is none. |
