#### 6.3.1 Design Review Queue

{{r3-06-design-review-queue width=100% align=center}}

**Description:** Displays submitted Member design requests and allows Staff and Managers to filter by review status, reload the queue, and open a request in Design Review Details.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Lọc trạng thái | Filters by All, Pending review, Accepted, Rejected, or Clarification required. |
| **Làm mới** | Reloads the review queue. |
| Queue table | Displays reference code, submission time, sender, idea summary, image count, status, and **Thẩm duyệt**. |
| Empty state | Displays "Hiện không có yêu cầu nào đang chờ thẩm duyệt." when no items match. |

:::
