#### 6.1.6 My Ring Designs

{{r3-06-my-ring-designs width=100% align=center}}

**Description:** Displays a Member's saved ring designs and submitted custom design requests in two tabs, allowing the Member to inspect, edit, archive/restore designs, or open request details.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Tabs | Switches between **Mẫu nhẫn đã lưu** and **Yêu cầu chế tác**. |
| Hiển thị cả thiết kế đã xóa/lưu kho | Checkbox to include archived designs in the list. |
| Design card | Shows design code, status, version, package, option summary, and estimated price. |
| Design actions | **Xem chi tiết** (Design Evaluation), **Chỉnh sửa** (Ring Configuration), **Yêu cầu chế tác** (Design Request Workspace), and **Xóa** / **Khôi phục thiết kế**. |
| Request card | Shows request code, review status, feedback indicator, description, and **Xem chi tiết →**. |
| Empty state & pager | Prompts to create a first design/request when empty; paginates at 5 items per page. |

:::
