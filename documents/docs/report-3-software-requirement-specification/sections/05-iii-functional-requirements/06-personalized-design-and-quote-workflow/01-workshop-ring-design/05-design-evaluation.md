#### 6.1.5 Design Evaluation

{{r3-06-design-evaluation-1 width=100% align=center}}

{{r3-06-design-evaluation-2 width=100% align=center}}

**Description:** Displays the saved design's read-only preview, advisory cost, weight, and difficulty evaluation, allowing the owning Member to explore recommended workshops, edit, consult, or archive the design.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Header | Displays design code, version, and status badge (**Đã lưu** or **Đã lưu trữ**). |
| Chỉ số ước tính kỹ thuật | Shows advisory cost, estimated weight, difficulty score, level, advice, and policy version. |
| Advisory & surface warnings | Displays surface or difficulty warnings when returned by the evaluation. |
| Configuration summary | Lists selected material, shape, dimensions, gemstones, attachments, and engraving. |
| Recommended workshop | Shows the recommended workshop package (or custom consultation guidance if too risky). |
| **Chỉnh sửa thiết kế** / **Tư vấn thiết kế** | Opens Ring Configuration in edit mode or starts Consultation Chat with design context. |
| **Khám phá các workshop** / **Xem danh sách mẫu thiết kế đã lưu** | Navigates to the workshop catalogue or My Ring Designs. |
| **Xóa khỏi danh sách lưu** | Opens a confirmation dialog to archive the design. |

:::
