#### 6.2.2 AI Feature Analysis

![](assets/screens/39-ai-feature-analysis.png)

This screen allows Members to:

- View recognized design components and the analysis state.
- Review and edit supported options, with current estimate and difficulty reassessment.
- Review the candidate features and current estimate context, then wait for Staff or Manager human review.
- Revise the current design or request clarification when the reviewer requires it.
- Receive safe retry or follow-up guidance when analysis is pending or fails.

| Field Name | Description |
| --- | --- |
| Preview / design canvas | Illustrative area for the selected or uploaded design; it is not proof that a design has been analyzed or approved. |
| Material / size / details | Supported configuration selections, validated for the selected package, branch and design compatibility. |
| Step indicator | Displays journey progress; the example step count is not an approved fixed workflow length. |
| Estimated price / difficulty | Read-only estimate context based on current options and configured rules; it is not an AI decision or final payable amount. |
| Save Draft / Send for Review | Illustrative actions. Submission requires the current eligible Member/design context. |
| Image-processing consent text | Shows the recorded consent version and processing state; the original affirmative consent remains server-side evidence. |
