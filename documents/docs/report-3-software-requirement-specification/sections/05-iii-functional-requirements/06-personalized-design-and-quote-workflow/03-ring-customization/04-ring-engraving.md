#### 6.3.4 Ring Engraving

![Ring Engraving mockup](assets/screens/45-ring-engraving.png)

This screen allows Guests and Members to:

- Choose supported workshop engraving options or enter permitted engraving content.
- Review validation against the configured content and placement rules.
- Confirm engraving as part of the workshop design; it does not create an arbitrary retail variant.

| Field Name | Description |
| --- | --- |
| Preview / design canvas | Illustrative area for the selected or uploaded design; it is not proof that a design has been analyzed or approved. |
| Material / size / details | Supported configuration selections, validated for the selected package, branch and design compatibility. |
| Step indicator | Displays journey progress; the example step count is not an approved fixed workflow length. |
| Estimated price / difficulty | Read-only estimate based on current options and configured rules; it is not a final payable amount. |
| Save Draft / Send for Review | Illustrative actions. Submission requires the current eligible Member/design context. |
| Image-processing consent text | Informational label in the frame; a consent statement alone is not evidence of an affirmative recorded choice. |
