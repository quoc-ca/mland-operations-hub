#### 6.2.1 Design Request Workspace

{{r3-06-design-request-workspace-1 width=100% align=center}}

{{r3-06-design-request-workspace-2 width=100% align=center}}

**Description:** Displays the custom design request form and allows authenticated Members to describe their ring idea, attach up to five quality-checked reference images, optionally link a saved ring design, accept image consent, and submit for review.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| **Xem yêu cầu của tôi** | Opens the **Yêu cầu chế tác** tab in My Ring Designs. |
| Attached ring design | Dropdown to attach an owned saved ring design with a preview card and **✕ Gỡ đính kèm**. |
| Mô tả ý tưởng thiết kế | Optional idea description up to 4,000 characters with a live counter. |
| Reference images | Uploads up to 5 JPEG/PNG/WEBP images (≤ 5 MB, ≤ 4096 × 4096 px) with sharpness check status. |
| Image consent | Required terms dialog and checkbox shown when at least one image is attached. |
| **Gửi yêu cầu thiết kế** | Submits the request once valid and opens Design Request Details. |

:::
