#### 11.1.1 Executive Revenue Dashboard

![](assets/screens/61-executive-revenue-dashboard.png)

This screen allows Managers to:

- Open it as the Manager home page: Vận hành hôm nay and Việc gần đây cần chú ý sit around the revenue report, which uses the full page width.
- Choose Ngày, Tuần, Tháng or Năm in Vietnam time and a date, and all branches (Tất cả) or one branch with a single click.
- View approved revenue and business KPIs calculated from verified records, each compared with the previous period of the same length.
- View workshop and retail trend charts by hour for a day, by day for a week or month and by month for a year, with each value written on its bar or point.
- See the best sellers for the same filters: the top 5 products and the top 5 workshop packages.
- Read every label in Vietnamese or English with the VI/EN switch.
- View the same figures per branch, and identify missing, delayed or incomplete metrics and retry when eligible.
- Access this dashboard as an authorized Manager only.

| Field Name | Description |
| --- | --- |
| Kỳ báo cáo / Chi nhánh | Period type, date and branch scope; an invalid filter keeps the last valid result. |
| Tổng doanh thu | Verified retail plus workshop revenue. Manager-only data; omitted for Member, Staff and Admin. |
| Doanh thu bán lẻ | Paid retail orders after discounts, without shipping fees, confirmed by VNPay or counter cash. |
| Doanh thu workshop | Workshop invoices fully paid (finalized folios) in the period. |
| Vé đặt / Lượt check-in / Tỷ lệ vắng mặt / Lấp đầy | Workshop places booked, check-ins, no-show rate, and fill rate (booked places over session capacity). |
| Xu hướng workshop | Places registered, check-ins, no-shows, cancellations and workshop revenue over the period; revenue and participants side by side, then tickets booked and cancelled. |
| Xu hướng bán lẻ | Orders placed, paid and cancelled or expired, and retail revenue over the period. |
| Bán chạy nhất | Top 5 sản phẩm bán chạy ranks products by units in paid retail orders; Top 5 gói workshop đặt nhiều nhất ranks packages by confirmed tickets. Each row shows rank, name, count (chiếc or vé) and a bar; hovering or focusing it shows the amount before discounts and the share of the five. An empty period, an unreadable list or a failed load (with Thử lại) is stated without hiding the rest of the page. |
| Chart values and colours | Each non-zero value is written on its bar or point (only each series' peak for more than 16 points); count axes use whole numbers. Retail amber, workshop blue, paid orders green, utilization violet, totals dark. |
| Change indicator | ▲ or ▼ versus the previous period; Kỳ trước chưa có when there is no previous data. |
| Scope and data notices | Display current scope and unavailable or delayed data; incomplete figures are never shown as complete. |
