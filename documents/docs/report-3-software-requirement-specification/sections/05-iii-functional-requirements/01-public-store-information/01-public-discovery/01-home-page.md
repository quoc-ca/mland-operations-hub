#### 1.1.1 Home Page

![](assets/screens/01-home-page.png)

This screen allows visitors and Members to:

- Browse the shop introduction and available shopping or workshop journeys.
- Open Product Catalogue, Workshop Package List or Review List.
- Sign in before entering a Member-only custom-order or purchase journey.

| Field Name | Description |
| --- | --- |
| Hero and image | Read-only introduction and illustrative ring/workshop image; supplied artwork is not a catalogue record. |
| Book Workshop / Explore Rings | Navigation actions to Workshop Package List and Product Catalogue. |
| Journey cards | Entry points for ready rings, workshops, custom requests and reviews; Member-only actions require authentication. |
