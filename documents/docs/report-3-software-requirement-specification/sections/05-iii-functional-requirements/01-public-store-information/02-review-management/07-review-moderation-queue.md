#### 1.2.7 Review Moderation Queue

This screen allows Staff and Managers to:

- See the reviews they can moderate, including public, hidden and removed reviews.
- Filter the reviews by status.
- See their own role and a notice of what each role may do.
- Open a review in Review Moderation Details.

Only Staff and Managers can open this screen; other signed-in roles are sent to the not-found page. Moderation authority is still checked by the server.

| Field Name | Description |
| --- | --- |
| Quay lại Trang chủ | Returns to the home page. |
| Role notice | States that Staff may only hide reviews, while Managers may hide, remove, restore and reply. |
| Vai trò hiện tại | "Quản lý (MANAGER)" or "Nhân viên (STAFF)". |
| Lọc trạng thái | "Tất cả", PUBLIC, HIDDEN or REMOVED; applied to the loaded list at once. |
| Shown count | Number of reviews matching the filter out of all loaded reviews. |
| Review card | Stars, status badge, masked name, text, photos, current Manager reply, package, target type and creation time. |
| Xem chi tiết | Opens Review Moderation Details for the review. |
| Empty message | "Chưa có đánh giá công khai." when no review matches the filter. |
