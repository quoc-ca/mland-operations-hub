#### 1.2.5 Create Review

This screen allows Guests and Members to:

- Write a review for one eligible source chosen from the authenticated Member Eligible Review Sources: a checked-in workshop attendance or a picked-up or delivered retail order line.
- Give a 1–5 star rating, optional text and up to 3 photos.
- Choose to post anonymously; the choice is fixed once the review is submitted.
- Publish the review, which becomes public at once and opens its Review Details.

A source can have only one review. The screen cannot be used without a selected source. Guest creation is not supported. Staff, Managers and Admins cannot create reviews.

| Field Name | Description |
| --- | --- |
| No source selected | "Vui lòng chọn nguồn đủ điều kiện trước." with links back to the Public Review List and Eligible Review Sources. |
| Guest notice | For a Guest: sign in is required before eligible sources or the review form can be opened. |
| Source information | Source label and "Mã tham chiếu" of the chosen source; it cannot be changed here. |
| Số sao (1–5) | Required star rating, 5 by default. |
| Nội dung đánh giá | Optional text, at most 2,000 characters, with a character counter. |
| Gắn ảnh trải nghiệm | Optional JPEG, PNG or WebP photos, at most 3 and at most 10MB in total, with previews and a remove button per photo. |
| Đánh giá ẩn danh | When ticked, the reviewer's name is not shown publicly; otherwise the name is partly masked. |
| Đăng đánh giá | Submits the review; on success shows "Đánh giá đã được đăng công khai." and opens Review Details. |
| Error messages | For example a source that already has a review or a source that is no longer eligible. |
