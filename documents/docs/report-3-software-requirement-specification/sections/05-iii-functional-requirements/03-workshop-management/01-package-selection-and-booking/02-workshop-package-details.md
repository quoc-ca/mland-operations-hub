#### 3.1.2 Workshop Package Details

{{r3-workshop-package-details width=100% align=center}}

This screen allows Guests and Members to:

- Read a published package's description, price per ticket and package rules.
- Choose a branch that sells the package and a date range, then pick the required number of sessions.
- Choose the number of tickets within the package range and the seats left in the chosen sessions.
- Add the selection to the workshop cart, or book it at once with **Đặt ngay**.
- Jump to the package's reviews.

Seat counts on this page are indicative only; no seat is held until the booking is confirmed. A package sold at no branch shows no booking controls.

| Field Name | Description |
| --- | --- |
| Package rules | "Quy định của gói workshop": number of sessions, tickets per booking, whether all sessions must be at the same branch, minimum slot gap on the same day, and the deposit policy (up to 200,000 VND per ticket at booking, the rest paid at the branch). |
| Price | Price per ticket ("/ vé") after the best automatic discount and the best usable voucher (a public voucher with uses left, or a saved usable voucher of the Member; never one limited to sessions or dates. A Guest also sees the public voucher counted, although only a Member can use a voucher); the note says the final price is quoted by the system at booking. |
| Offers on this package | Shop discounts applied automatically (including one that needs a bigger order, "Applied on orders from {amount}") and the vouchers covering the package with their minimum and a "View and save code" or "View conditions" link; a visitor who is not signed in gets a sign-in link. Hidden when there is no offer. |
| Chi nhánh | Branches where the package is currently sold. If the chosen branch stops selling it, the screen asks the customer to choose another branch. |
| Từ ngày / Đến ngày | Date range for the session search. |
| Session choice | "Chọn {count} ca workshop (đã chọn x/y)": session buttons with date and time and "Còn {count} chỗ" or "Hết chỗ"; paged when there are many sessions. |
| Số lượng vé | Ticket stepper, enabled only after all required sessions are chosen; the maximum is the lower of the package maximum and the seats left. |
| Thêm vào giỏ | Adds the package, sessions and ticket count as one line of the workshop cart and shows "Đã thêm vào giỏ hàng thành công". |
| Đặt ngay | Opens Session and Participant Booking with the chosen branch, sessions and ticket count. |
| Xem đánh giá của gói này ↓ | Scrolls to the reviews of this package. |
| Messages | "Gói workshop không tồn tại hoặc đã ngừng cung cấp.", "Gói này hiện chưa được bán tại chi nhánh nào.", or no session in the chosen period. |
