#### 3.1.1 Workshop Package List

![](assets/screens/19-workshop-package-list.png)

This screen allows Guests and Members to:

- Browse the workshop packages that are currently published, nine package cards per page.
- See each package's number of sessions, ticket range per booking and price per person.
- See the price per ticket after the best automatic discount and the best usable voucher, with the original price struck through and a "Price after voucher {code}" tag (with the branch for a branch-limited voucher), plus the offer badges, when they apply.
- Open a package's details and session choice with **Chọn ca & đặt**.
- Go to the ring designer before the class through the design prompt.
- Read the review summary of all packages at the bottom of the page.

Browsing the list never holds a seat.

| Field Name | Description |
| --- | --- |
| Design prompt | Asks whether the customer wants to choose the ring shape or material first; "Cấu hình mẫu nhẫn ngay →" opens the ring designer. |
| Package card | Package name, description and an illustration. |
| Sessions chip | "⏱ {count} buổi": the number of sessions a booking of this package needs. |
| Tickets chip | "{count} vé" or "{min}–{max} vé": the number of tickets allowed in one booking. |
| Same branch chip | "📍 Cùng một chi nhánh", shown only for a package with several sessions that must all be at one branch. |
| Price | Price per person ("/ người"), after the best automatic discount and the best usable voucher (a public voucher with uses left, or a saved usable voucher of the Member; never one limited to sessions or dates. A Guest also sees the public voucher counted, although only a Member can use a voucher); otherwise the public price. |
| Offer badges | The best automatic discount (or one "off orders from {amount}"), up to two vouchers ("Code" or "Save code", with any minimum) and, for a visitor who is not signed in, "Sign in to use a code". |
| Chọn ca & đặt | Opens Workshop Package Details at the session choice. |
| Load / empty states | "Đang tải danh sách gói workshop...", an error with **Thử lại**, or "Hiện chưa có gói workshop nào được mở bán." |
| Pager | Moves between pages of package cards. |
