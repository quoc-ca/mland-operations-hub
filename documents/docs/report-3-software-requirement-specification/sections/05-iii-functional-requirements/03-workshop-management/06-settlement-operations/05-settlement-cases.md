#### 3.6.5 Settlement Cases

{{r3-settlement-cases width=100% align=center}}

This screen allows Managers to:

- List the settlement and compensation cases that the server still serves.
- Filter the cases by type and by status.
- Reload the list.
- Follow the links to the Refund Queue for refunds and to Change Requests for ticket changes.

The list is read-only and shows filtered, safe data; payment and provider evidence stays behind the backend. Per-ticket work (folio, refunds, cancellations, changes) is done on the Settlement Workspace, Refund Queue, Ticket Actions and Change Requests screens, not here. Access is decided by the backend.

| Field Name | Description |
| --- | --- |
| "Loại" filter | "Tất cả", "Khách hủy vé", "Bắt buộc đổi ca" or "Khắc phục do Mland hủy"; kept in the page URL. |
| "Trạng thái" filter | "Tất cả", "Đang mở", "Chờ nhà cung cấp", "Đã giải quyết", "Đã từ chối" or "Thất bại"; kept in the page URL. |
| "Làm mới" | Reloads the case list. |
| "Hồ sơ" | Case reference. |
| "Loại" | Case type label. |
| "Trạng thái" | Case status label. |
| "Đặt chỗ" | Booking code of the case. |
| Empty state | "Không tìm thấy hồ sơ quyết toán nào." |
| Queue links | "hàng đợi hoàn tiền" opens Refund Queue; "hàng đợi yêu cầu đổi vé" opens Change Requests. |
