#### 3.4.2 Package Add-ons

{{r3-package-add-ons width=100% align=center}}

This screen allows Managers to:

- Choose a workshop package and a branch to see the add-ons configured for that pair.
- Create an add-on as a draft with a description and a price in VND.
- Edit an add-on that is not retired.
- Activate a draft add-on so customers can choose it, or retire an active one.

Customers can only choose an add-on while it is "Đang bán". Staff can open the page; changes are checked by the server.

| Field Name | Description |
| --- | --- |
| Gói workshop | Required package of the add-on scope. |
| Chi nhánh | Required branch of the add-on scope. |
| Mô tả add-on | Required description shown for the add-on, for example engraving. |
| Đơn giá (VND) | Required price in VND. |
| Tạo bản nháp / Lưu thay đổi | Creates a draft add-on, or saves the add-on being edited; **Hủy chỉnh sửa** leaves the edit. |
| Danh sách Add-on đã cấu hình | Columns Mô tả add-on, Mã tham chiếu, Đơn giá, Trạng thái and Thao tác, with the count for the chosen scope. |
| Trạng thái | "Bản nháp", "Đang bán" or "Ngừng bán". |
| Chỉnh sửa / Kích hoạt / Ngừng bán | **Chỉnh sửa** is disabled for a retired add-on; **Kích hoạt** appears on a draft and **Ngừng bán** on an active add-on. |
| Empty states | "Vui lòng chọn gói workshop và chi nhánh ở trên." or "Chưa có add-on nào trong phạm vi này." |
