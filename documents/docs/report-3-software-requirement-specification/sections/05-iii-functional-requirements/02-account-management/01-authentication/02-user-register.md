#### 2.1.2 User Register

{{r3-02-user-register width=100% align=center}}

**Description:** Displays the registration form and allows Visitors to create a new Member account using email and password or Google.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Sign in with Google | Creates or signs in a Member account via Google when Firebase is configured. |
| Email address | Required valid email address; rejects duplicates. |
| Password | Required, masked, at least 6 characters. |
| Confirm password | Required; must match Password. |
| Terms notice | States agreement to the terms of use upon registration. |
| Register | Creates the account, sends a verification email, and signs in. |
| Error message | Displays duplicate email, weak password, or network errors. |
| Sign in now | Link to User Login. |
| ← Back | Returns to Home Page. |

:::
