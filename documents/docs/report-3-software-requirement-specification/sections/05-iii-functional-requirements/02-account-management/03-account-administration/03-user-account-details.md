#### 2.3.3 User Account Details

{{r3-02-user-account-details width=100% align=center}}

**Description:** Displays one account's overview and management controls, allowing Admins to edit profile info, reassign Staff/Manager roles and locations, resend invitations, or suspend/restore accounts.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Account header | Displays name, account code, sign-in identity, and status badge. |
| Account overview | Shows role, status, assigned location(s), session revocation state, version, and timestamps. |
| Resend invitation | Pending Staff/Manager only; issues a new 48-hour setup link after cooldown. |
| Suspend / Restore account | Opens suspension reason modal or restores a suspended account (disabled for ADMIN). |
| Edit profile information | Updates full name and phone number via **Save profile** (hidden for ADMIN). |
| Assign role & location | Staff/Manager only; switches between STAFF and MANAGER and updates locations. |
| Partner scope & permissions | Carrier only; notes that role and location are fixed. |
| ← Back to account list | Returns to User Account List. |

:::
