#### 2.3.2 New Internal Account

{{r3-02-new-internal-account width=100% align=center}}

**Description:** Displays the internal provisioning form and allows Admins to create Staff, Manager, or Carrier (GHTK) accounts.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Internal role | Selects STAFF, MANAGER, or CARRIER (GHTK) with role scope hints. |
| Identity & invitation email | Required email; receives a 48-hour setup link for Staff and Manager. |
| Initial password | Carrier only; required write-only password, at least 6 characters. |
| Full name / Partner display name | Required, up to 100 characters. |
| Contact phone number | 7 to 30 characters; required for Carrier, optional for Staff and Manager. |
| Work location | Staff and Manager only; 1 location (radio) for Staff, ≥ 1 (checkboxes) for Manager. |
| Create account / Cancel | Submits the form or returns to User Account List. |
| Created summary | Displays account ID, role, email, status, and links to details or list. |

:::
