#### 2.3.4 Role Catalogue

This screen allows Admins to:

- Look up the five fixed system roles (MEMBER, STAFF, MANAGER, CARRIER, ADMIN) and the scope and permissions of each.
- Read the role governance rules.
- Return to User Account List to assign roles on an account.

The catalogue is read-only: roles cannot be added, renamed, deleted or given different permissions. Only the ADMIN role can open it.

| Field Name | Description |
| --- | --- |
| Accounts / Roles tabs | Admin navigation between User Account List and this screen. |
| Read-only badge | "Read-only · 5 fixed roles". |
| Role table | One row per role from the system: role code and its scope and permissions text. |
| Role governance rules | One role per account; MEMBER comes from self-registration; STAFF has exactly one branch; MANAGER has one or more branches but system-wide management scope; CARRIER is created ACTIVE by an Admin, has no branch and cannot change role; ADMIN cannot be suspended or edited here. |
| Tip | Assigning STAFF or MANAGER is done in User Account Details by choosing the branch. |
| Load error | "Could not load the system role catalogue." |
