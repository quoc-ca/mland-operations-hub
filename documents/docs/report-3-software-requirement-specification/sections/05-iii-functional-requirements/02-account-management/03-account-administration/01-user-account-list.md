#### 2.3.1 User Account List

{{r3-02-user-account-list width=100% align=center}}

**Description:** Displays the system account directory and allows Admins to search, filter by role or status, open account details, or navigate to create an internal account.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| + Create internal account | Opens New Internal Account. |
| Search | Matches email or user name. |
| Role | Filters by All roles, MEMBER, STAFF, MANAGER, CARRIER, or ADMIN. |
| Status | Filters by All statuses, ACTIVE, PENDING_SETUP, or SUSPENDED. |
| Search button | Applies search and filter criteria. |
| Account table | Displays ID, Sign-in email, Role, Status badge, Last updated, and **Details**. |
| Empty state | Displays "No accounts match the current filters." when empty. |
| Pager | Shows 20 accounts per page with **Previous**, **Next**, and total count. |

:::
