#### 2.2.3 Address Book

{{r3-02-address-book width=100% align=center}}

**Description:** Displays saved delivery addresses (up to 10) and allows Members, Staff, Managers, and Admins to add, edit, delete, or set a default address.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Saved count | Displays `Saved: n/10 addresses`; disables **+ Add new address** at 10. |
| Address card | Shows recipient name, phone, full address, **Default** badge, and type (Home or Office). |
| Edit / Delete / Set as default | Card actions; **Delete** is disabled on the default address while others exist. |
| Confirm address deletion | Confirmation modal with **Cancel** and **Confirm deletion**. |
| Recipient full name | Required, up to 255 characters; unlocks the next fields sequentially. |
| Phone number | Required 10-digit Vietnamese mobile number (`03`, `05`, `07`, `08`, `09`). |
| Province / Ward drop-downs | Required province and searchable ward/commune selectors. |
| Street address | Required house number, building, and street. |
| Address type / Default | Home or Office selector and default address checkbox. |
| ← Back to profile | Returns to User Profile. |

:::
