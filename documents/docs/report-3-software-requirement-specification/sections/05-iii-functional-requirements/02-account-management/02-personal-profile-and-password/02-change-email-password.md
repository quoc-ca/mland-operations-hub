#### 2.2.2 Change Email / Password

{{r3-02-change-email-password width=100% align=center}}

**Description:** Displays the password and email update sections on the profile page, allowing signed-in users to change their password or request a sign-in email change (Carrier accesses password only).

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Current password | Required to reauthenticate before changing password or email. |
| New password | Required, masked, at least 6 characters. |
| Confirm new password | Required; must match New password. |
| Update password | Submits the password change and clears fields on success. |
| New email address | Required valid email address not used by another account. |
| Request email change | Sends a verification link to the new address; updates email after verification. |
| Google account notice | Replaces password/email forms for Google-only accounts. |
| ← Back to the carrier portal | Shown on the Carrier-only password page. |

:::
