**Description:** Displays personal account information, verification status, and security shortcuts, allowing Members, Staff, Managers, and Admins to view and update their profile.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Verification banner | Shown when unverified; includes **Resend verification email** with a cooldown timer. |
| Email verification status | Displays Checking…, Verified, or Not verified with **Reload verification**. |
| Profile summary | Displays name, role and email badges, email, phone, account ID, status, and join date. |
| Quick actions | **Edit profile**, **Change password**, and **Change email** scroll to sections; **Manage addresses →** opens Address Book. |
| Sign-in address | Read-only email; updated in the Change Email section. |
| Full name | Required, up to 100 Unicode characters. |
| Phone number | Optional, 7 to 30 characters. |
| Save changes / Reset | **Save changes** requires verified email; **Reset** restores stored values. |
| ← Back to home | Returns to Home Page. |

:::
