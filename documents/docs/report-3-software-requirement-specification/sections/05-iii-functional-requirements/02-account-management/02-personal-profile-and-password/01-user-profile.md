#### 2.2.1 User Profile

![](assets/screens/08-user-profile.png)

This screen allows Members to:

- View the signed-in Member's own permitted profile information.
- Update permitted name and contact fields and complete contact verification where required.
- Open Change Password when the account has locally managed credentials.

| Field Name | Description |
| --- | --- |
| Email | Displays the owning Member's stored email; contact changes requiring verification are not applied until verification succeeds. |
| Full name | Text profile field; load the Member's permitted stored value. |
| Phone | Contact field for the owning Member. |
| Continue | Submits only the current account action after validation; failure leaves the user in a safe recoverable state. |
| Google / Email / Support | Alternative access/help labels; supported providers and exact interaction controls follow the approved account flow. |
| Privacy and recovery panel | Informational text; recovery responses must not disclose whether an account exists. |
