#### 4.1.1 Product Catalogue

![](assets/screens/08-product-catalogue.png)

This screen allows visitors and Members to:

- Browse published products in active categories as a card grid with a total result count.
- Search by product name and filter by category, inclusive price bounds and products that can be bought; filters are applied together with **Apply** and kept in the page URL.
- Sort by default order, name A–Z, ascending or descending price, or newest.
- See on each card the price after automatic discounts and the best voucher, with the offer badges, without the card becoming a quote.
- Add a size to the cart through the Quick add box, or open the product's details.

Only sizes with an applied price are shown and counted in the price, the price filter and the price sort.

| Field Name | Description |
| --- | --- |
| Search | Text input matched against product names; empty input lists all public products. |
| Category | Selection of active categories; "All" removes the category filter. |
| Price from / to (₫) | Optional whole-VND bounds; price and availability must match the same size. |
| Sort by | Default, Name A–Z, Price: low to high, Price: high to low or Newest. |
| Only products you can buy | Checkbox restricting results to products with a size that can be bought at one or more branches. |
| Product card | Image, category, name, price or price range after the largest automatic discount with the original price struck through, then the best voucher for one item labelled "Price after voucher {code}" ("· at {branches}" for a voucher limited to some branches), offer badges and In stock / Out of stock state. The price is for viewing only. |
| Add to cart icon | Opens the Quick add box with the same size grid, branch list, quantity selector, Add to cart and Buy now as Product Details; it does not create an order or hold. |
| Pager (Previous / Next) | Moves between result pages. |
