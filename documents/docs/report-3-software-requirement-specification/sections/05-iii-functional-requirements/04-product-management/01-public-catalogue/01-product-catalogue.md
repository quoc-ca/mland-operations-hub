#### 4.1.1 Product Catalogue

![](assets/screens/10-product-catalogue.png)

This screen allows visitors and Members to:

- Browse published products in active categories as a card grid with a total result count.
- Search by product name and filter by category, inclusive price bounds and in-stock availability; filters are applied together with **Áp dụng** and kept in the page URL.
- Sort by default order, name A–Z, ascending or descending price, or newest.
- See active automatic discounts and eligible vouchers on each card without the card becoming a quote.
- Add a variant to the cart through a quick-add dialog, or open the product's details.

| Field Name | Description |
| --- | --- |
| Search (Tìm kiếm) | Text input matched against product names; empty input lists all public products. |
| Category (Danh mục) | Selection of active categories; "Tất cả" removes the category filter. |
| Price from / to (Giá từ / Giá đến) | Optional whole-VND bounds; price and availability must match the same variant. |
| Sort (Sắp xếp) | Mặc định, Tên A–Z, Giá tăng dần, Giá giảm dần or Mới nhất. |
| In stock only (Chỉ hiện sản phẩm còn hàng) | Checkbox restricting results to products with a sellable variant. |
| Product card | Image, category, name, applied price or price range, struck-through original price when an automatic discount applies, offer badges and Còn hàng / Tạm hết hàng state. |
| Add to cart icon | Opens the quick-add dialog to choose size, branch and quantity; it does not create an order or hold. |
| Pager (Trang trước / Trang sau) | Moves between result pages. |
