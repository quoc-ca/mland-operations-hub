#### 4.1.2 Product Details

![Product Details mockup](assets/screens/11-product-details.png)

This screen allows visitors and Members to:

- View product images, description and configured size/engraving variants.
- Select an existing variant and view its applied approved whole-VND price and logical availability.
- As an active Member, add an available variant to the cart with integer quantity 1–99 per variant across at most 50 cart lines.
- Choose only configured retail engraving options; browsing and cart entry do not create a hold.

| Field Name | Description |
| --- | --- |
| Search | Text input for discovery; product search trims input and matches name/description without case sensitivity. |
| Category tabs | Illustrative All, Rings, Workshop and Reviews navigation/filter labels; they do not establish catalogue categories. |
| Image / name / material / price | Read-only illustrative cards; live product amounts must use applied approved variant prices. |
| View Details | Opens the selected accessible record; it does not create a cart, order or hold. |
