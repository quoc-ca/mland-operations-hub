#### 4.1.2 Product Details

![](assets/screens/11-product-details.png)

This screen allows visitors and Members to:

- View the product's images, category, description and stock state.
- See the price range, or the selected size's price after applicable automatic discounts.
- Review the offers that apply to this product and open a voucher's details to save it.
- Select a size, processing branch and quantity, then add the variant to the cart or buy it immediately.
- Open the ring size conversion guide and read public customer reviews for the product.

| Field Name | Description |
| --- | --- |
| Breadcrumb / name | Read-only path "Sản phẩm / {category}" and product name. |
| Image gallery | Product images with thumbnails and alternative text. |
| Price | Applied Manager-approved price or range; an automatic discount shows the discounted price beside the struck-through original. Displayed prices remain indicative until checkout. |
| Offers for this product (Ưu đãi cho sản phẩm này) | Lists automatic discounts and eligible vouchers with their conditions; **Xem và lưu mã** opens the voucher details. |
| Size | Selectable configured sizes; unavailable sizes cannot be chosen. **Bảng Quy Đổi Kích Cỡ** opens the size guide. |
| Branch (Chi nhánh) | Selection of branches selling the chosen size, with the remaining quantity. |
| Quantity (Số Lượng) | Integer stepper limited by the available quantity of the selected size and branch. |
| Thêm Vào Giỏ Hàng / Mua Ngay | Adds the variant to the Member's cart or goes straight to checkout; a visitor is asked to sign in. Neither action creates a hold. |
| Customer reviews (Đánh giá từ khách hàng) | Public review aggregate, sort order and star filter for this product. |
