#### 4.2.5 Product Categories

![](assets/screens/86-product-categories.png)

This screen allows Staff and Managers to:

- Create a product category with a name and description.
- Browse categories by name and activity state.
- Edit a category's name and description.
- Deactivate or reactivate a category after reviewing the products it affects.

| Field Name | Description |
| --- | --- |
| Category name (Tên danh mục) | Required text input for a new category. |
| Category description (Mô tả danh mục) | Optional text describing the category. |
| Tạo danh mục | Creates the category as active. |
| Search / state filter | "Tên danh mục" search with **Tìm**, and Tất cả / Đang hoạt động / Ngừng hoạt động. |
| Category row | Name, state badge (Đang hoạt động or Ngừng hoạt động) and description. |
| Sửa | Opens inline editing of the name and description with **Lưu** / **Hủy**. |
| Ngừng hoạt động / Kích hoạt | Opens a confirmation listing how many products belong to the category, with links to them; an inactive category cannot be chosen for new products and its products are excluded from the public catalogue. |
