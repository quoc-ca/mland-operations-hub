#### 4.2.5 Product Categories

![](assets/screens/51-product-categories.png)

This screen allows Staff and Managers to:

- Create a product category with a name and description.
- Find categories by part of the name and by status.
- Edit a category's name and description.
- Deactivate or reactivate a category after reviewing the products it affects.

| Field Name | Description |
| --- | --- |
| Category name | Required text input for a new category. |
| Category description | Optional text describing the category. |
| Create category | Creates the category as active. |
| Find a category / Status | "Category name" search with **Find** or Enter, and All / Active / Inactive; both are applied before paging and kept in the page URL, and "No category matches the filter." is shown when nothing matches. |
| Category row | Name, state badge (Active or Inactive) and description. |
| Edit | Opens inline editing of the name and description with **Save** / **Cancel**. |
| Deactivate / Activate | Opens a confirmation stating how many products belong to the category, with links to them; an inactive category cannot be chosen for new products and its products are excluded from the public catalogue. |
