#### 4.2.4 Price Proposal Form

![](assets/screens/50-price-proposal-form.png)

The price proposal form is the **Price proposals** section of Product Management Details. It allows Staff and Managers to:

- Review each size's applied price and its full price history.
- Enter a new proposed price for one size, or a common or individual price for several sizes at once.
- Save proposals as drafts, then submit them to the Manager for review.
- Apply a Manager-approved price as a separate action.
- As a Manager, change the price of a size of a published product in one step.

Saving or submitting a proposal never changes the applied price or the publication state.

| Field Name | Description |
| --- | --- |
| Size heading | Size, the price customers currently pay for it and the state of its current round; with more than 3 sizes each size can be collapsed, and sizes with a draft, pending or approved-not-applied round start open. |
| Price history of size N | Per round: Revision, one combined state (Applied, Approved, not applied yet, Pending, Draft, Rejected or Superseded), proposed amount, approved amount and rejection reason. |
| Submitted / decided by | Who submitted and decided each round, the submitter's branches at submission and the times. |
| Propose a new price / Revise proposed price | Shown to Staff, and to a Manager only before the first publication or for a size with a pending proposal. Positive whole-VND amount; **Save** saves it as a draft and **Cancel** discards it. Revising a pending proposal returns it to draft. |
| Submit price | Submits the saved draft to the Manager; only after the product's first publication. |
| Change price | Manager only, for a product that has been published before (including a hidden one) and a size without a pending proposal: "New selling price (VND)" and "Apply the price right after approving" (ticked by default); **Save** creates, submits and approves the proposal at that price, then applies it if ticked. If a step fails, the earlier steps are kept and the Manager continues from the current state. |
| Edit proposed prices of several sizes | Bulk editor showing the applied price, current proposal, new proposal and difference per size, with "Shared proposed price (₫)", **Save and submit** (after the first publication) and **Only save drafts**. |
| Apply approved price | Applies an approved, not yet applied price to the size; several sizes can be applied together. |
