#### 10.1.2 Voucher Details

![](assets/screens/live/11-voucher-details.png)

This screen allows visitors and Members to:

- View a voucher's ticket and, as a Member, save a voucher that must be saved; a public voucher has no Save button because it needs no saving.
- Read the full conditions: validity window, minimum value, points combination, branches, products or packages and usage limits.

It opens from the Conditions link of a voucher ticket, or from a product or workshop page through "View and save code" or "View conditions". The same screen also shows an active automatic discount, with its name as the title and no voucher ticket or Save button.

**Field Description**

| Field Name | Description |
| --- | --- |
| Voucher hub | Link above the title; returns to Voucher Store. |
| Title | "Voucher details" for a voucher; the programme name for an automatic discount. |
| Voucher ticket | Discount, minimum order value, branch restriction, programme name, code, expiry date and points combination. A voucher that must be saved shows the save button; a public voucher shows "Public code: no need to save it, pick it at checkout." |
| Offer | Programme name and discount. |
| Conditions | Valid period, Minimum amount, Combine with points (Yes or No), branches, products, sizes or workshop packages, workshop dates or sessions, Total uses and Uses per Member. A product voucher with no branch limit shows "All branches". |
| Not found state | "This offer does not exist or is no longer public" with **Back** to Voucher Store. |
| Footnote | "Offer cards are for information; whether a voucher applies is checked when you order." |
