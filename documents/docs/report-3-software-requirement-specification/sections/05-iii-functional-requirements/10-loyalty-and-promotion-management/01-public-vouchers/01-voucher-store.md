#### 10.1.1 Voucher Store

![](assets/screens/live/10-voucher-store.png)

This screen, titled **Voucher hub**, allows visitors and Members to:

- Browse the active vouchers that must be saved before use, all together or by retail-product or workshop scope.
- See each voucher's discount, minimum order value, branch restriction, code, expiry date and whether it can be combined with points.
- As a Member, save a voucher to My Saved Vouchers, which claims one of its uses; a visitor is asked to sign in first.
- Open a voucher's conditions.

Public vouchers need no saving and are not listed here: they show on product and workshop pages and are suggested at checkout. Automatic discounts are not listed either.

**Field Description**

| Field Name | Description |
| --- | --- |
| Hint | "These codes must be saved before use; each save claims one use for you. Public codes need no saving…" |
| Scope tabs | Options: All, Products, Workshops. Default: All. |
| My vouchers | Link at the right of the tabs; opens My Saved Vouchers. |
| Voucher ticket | Scope label, discount (with maximum for a percentage), "Minimum order {value}", "Only at: {branches}." when limited to branches, programme name, code, "Expires: {date}", "Combines with points" or "No points with it", and "Save to use". A voucher with no use left to claim is marked "All claimed"; one the Member has used up is marked "You used all your uses". |
| Save voucher / Sign in to save | Saves the voucher for the Member and claims one use, or sends a visitor to sign in. A saved voucher shows "Saved." with a **My vouchers** link. A refused save shows "All claimed" or "You have used your use of this code". A signed-in non-Member sees "Only members can save vouchers." |
| Conditions | Opens Voucher Details. |
| Load more | Loads further vouchers when there are more. |
| Empty state | "There are no vouchers to save right now." |
| Footnote | "Offer cards are for information; whether a voucher applies is checked when you order." |
