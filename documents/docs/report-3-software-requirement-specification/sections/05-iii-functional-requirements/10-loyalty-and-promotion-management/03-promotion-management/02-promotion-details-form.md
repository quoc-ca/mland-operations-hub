#### 10.3.2 Promotion Form

![](assets/screens/live/68-promotion-form.png)

This screen, titled **New promotion programme**, allows Managers to:

- Create a voucher or an automatic discount for retail products or workshops.
- Set the programme name, validity window and discount, by percentage with a maximum or by a fixed amount, plus a minimum eligible value.
- For a voucher, use the system-generated unique code, allow or forbid combining it with loyalty points, choose its distribution and set total and per-Member usage limits.
- Choose the programme's targets: branches and products or sizes for retail, packages, branches and sessions for a workshop voucher, or packages for a workshop automatic discount.

Existing programmes are edited from Promotion Details; the kind, scope, voucher code, targets and distribution cannot change after creation.

**Field Description**

| Field Name | Description |
| --- | --- |
| Unanswered create | If an earlier create got no answer, a notice offers **Send that same request again**, **Dismiss** and **See the programme list**. |
| Kind | Options: Voucher, Automatic discount. Default: Voucher. |
| Scope | Options: Products, Workshops. Default: Products. |
| Programme name | Required text input of up to 200 characters. |
| Voucher code | Voucher only. Read-only unique code generated by the system; **Generate another code** draws another. A code already taken is redrawn automatically when creating. |
| Starts / Ends | Date plus hour and minute, with the resulting date-time shown below ("That is: {at}"). Default: a 30-day window starting at the next quarter hour. |
| Discount type | Options: Percentage, Fixed amount. Default: Percentage. |
| Percentage / amount | "Percentage (%)" (above 0 and up to 100, at most 6 decimals) with a required "Maximum discount (₫)", or "Amount (₫)" for a fixed amount. Amounts are positive whole numbers. |
| Minimum amount (₫) | Minimum eligible amount. Default: 0, meaning no minimum. |
| Allow points together with this voucher | Voucher only; ticked by default. An automatic discount shows "An automatic discount always combines with points." instead. |
| Distribution | Voucher only. Options: "Public — no saving needed", "Must be saved — saving claims a use". Default: Public. The hint under the field explains each option. |
| Total uses / Uses per Member | Voucher only, under "Usage limits"; positive whole numbers. Uses per Member defaults to 1 and is fixed at 1 for a voucher that must be saved. |
| Targets | Retail: Branches (Options: All branches, Only some branches; Default: All branches) for a voucher, while a product automatic discount applies at every branch. Workshop voucher: package, branch and session, each "All" or exactly one item. Workshop automatic discount: one or more packages only. |
| Find a product | Retail only: search by name, product number or SKU, with Status (Options: All, Public, Not public yet or hidden; Default: All). **Choose all on this page** and **Clear all on this page** select or clear the products shown. Each product can be chosen whole or by size; chosen items are listed with **Remove**. |
| Create programme / Cancel | **Create programme** validates the configuration, creates the programme and opens its details with "Programme created."; **Cancel** returns to Promotion List. |
