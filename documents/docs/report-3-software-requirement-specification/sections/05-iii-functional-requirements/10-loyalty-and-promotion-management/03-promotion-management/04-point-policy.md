#### 10.3.4 Point Policy

![](assets/screens/live/70-point-policy.png)

This screen allows Managers to:

- View the loyalty-point policy currently in force and its version.
- Change how points are earned and spent; the change applies only to transactions accepted after saving.

**Field Description**

| Field Name | Description |
| --- | --- |
| Edit | Button on the **Current policy** card; opens the **Change policy** form. |
| Amount for 1 point (₫) | Shown as "1 point per {amount}"; a positive whole-VND amount. |
| Value of 1 point (₫) | Shown as "1 point = {amount}"; a positive whole-VND value. |
| Minimum points per use | Smallest number of points that can be spent at once; a positive whole number. |
| Maximum % payable with points | Highest percentage that points may cover of the amount after automatic discounts and vouchers, excluding shipping; above 0 and at most 100. |
| Rounding | Read-only rounding rule: "Round down (drop fractions)". |
| Version | Read-only policy version and creation time. |
| Change policy | The four editable values with **Save** and **Cancel**; success shows "New point policy saved." Earlier orders and history keep the policy they were accepted under. |
