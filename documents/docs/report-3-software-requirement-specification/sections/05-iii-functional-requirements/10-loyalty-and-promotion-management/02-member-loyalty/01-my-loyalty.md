#### 10.2.1 My Loyalty

![](assets/screens/live/35-my-loyalty.png)

This screen, titled **My points**, allows Members to:

- View their own available points, total balance and points held by orders or bookings that are not yet complete.
- Read the point policy currently in force: how points are earned, the value of one point, the minimum per use and the maximum share payable by points.
- Open My Saved Vouchers.
- Review their point history in the section below (see Point History).

One shared balance is used for both retail products and workshops. A visitor who is not signed in is asked to sign in; other signed-in roles are routed to the not-found page.

**Field Description**

| Field Name | Description |
| --- | --- |
| Signed-in gate | A visitor sees "Please sign in with a Member account to see this." |
| Available | Read-only points that can be spent now: the balance minus held points. |
| Balance | Read-only total point balance. |
| Held | Read-only points reserved by unfinished orders, with the note "Held points belong to unfinished orders; they are used or returned when the order is settled." |
| Policy rules | Read-only lines from the current point policy: "1 point per {amount}", "1 point = {amount}", "At least {points} points per use" and "Points cover at most {percent}% of an order". |
| My vouchers | Opens My Saved Vouchers. |
