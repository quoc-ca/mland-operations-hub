#### 10.2.3 My Saved Vouchers

![](assets/screens/live/37-my-saved-vouchers.png)

This screen, titled **My vouchers**, allows Members to:

- Review the vouchers they have saved, filtered by scope and split into still valid and expired or unusable.
- See each voucher's availability, code, discount and full conditions.
- Go to products or workshops to use a voucher, or find more vouchers in the Voucher Store.

Saving a public voucher does not reserve a use; a use is held only when an order is placed. Saving a voucher that must be saved claims one use for the Member. A visitor is asked to sign in; other signed-in roles are routed to the not-found page.

**Field Description**

| Field Name | Description |
| --- | --- |
| Hint | "Public vouchers: saving holds no use. "Must be saved" vouchers: saving claims one use for you." |
| Scope filter | Options: All, Products, Workshops. Default: All. Shown once the Member has a saved voucher. |
| Tabs | Options: Valid (usable or not started yet), Expired / Unusable, each with a count. Default: Valid, or Expired / Unusable when no voucher is valid. |
| Find more vouchers | Link at the right of the tabs; opens Voucher Store. |
| Voucher card | Scope badge, availability (Usable, Paused, Not started yet, Expired, No product or package left, No uses left or You have used all your uses), programme name, code and discount. |
| Conditions | Valid period, Minimum amount, Combine with points, targeted products, sizes, packages or branches, Total uses and Uses per Member. |
| Saved time | "Saved {date-time}": when the Member saved the voucher. |
| Use now | Shown for a usable voucher; opens the product catalogue or workshop list according to the voucher's scope. |
| Empty states | "You have not saved any voucher." with **See offers**; "No valid voucher." or "No expired or unusable voucher." for an empty tab. |
| Load more | Loads further saved vouchers when there are more. |
