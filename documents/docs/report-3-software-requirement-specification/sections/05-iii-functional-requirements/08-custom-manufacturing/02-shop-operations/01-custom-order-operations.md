#### 8.2.1 Custom Order Operations

{{r3-08-custom-order-operations width=100% align=center}}

**Description:** Displays all Member custom orders grouped by production stage and allows Staff and Managers to search orders, inspect design snapshots, and advance paid orders through production and GHTK handover.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| **Làm mới** | Reloads the custom order list. |
| Summary cards | Displays counts for waiting production, in production, ready for handover, and completed orders. |
| Search | Searches by order code, request code, customer name, email, or description. |
| Stage tabs | Filters by **Chờ chế tác**, **Đang gia công**, **Sẵn sàng giao hàng**, **Đã hoàn tất**, or **Tất cả đơn**. |
| Order card | Shows order code, status, linked request, quoted amount, customer/delivery info, design snapshot, GHTK tracking code, and reference images. |
| Stage action button | Advances the order to the next allowed stage (**Bắt đầu chế tác**, **Hoàn thành chế tác & Sẵn sàng giao**, or **Đóng gói xong & Bàn giao bưu tá GHTK**) with confirmation. |
| **Xem thêm** | Expands quote reference, deadline, production status, tracking, and reviewer note. |

:::
