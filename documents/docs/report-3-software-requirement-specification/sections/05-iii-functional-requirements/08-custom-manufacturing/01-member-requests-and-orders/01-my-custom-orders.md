#### 8.1.1 My Custom Orders

{{r3-08-my-custom-orders width=100% align=center}}

**Description:** Displays a Member's custom orders and design requests in two tabs, allowing Members to track status, pay unexpired quotes via VNPay, request new quotes, or submit clarification replies.

::: {.docx-table width="100%" columns="50%,50%"}

| Field Name | Description |
| --- | --- |
| Tabs | Switches between **Đơn hàng cá nhân (Orders)** and **Yêu cầu thiết kế (Requests)**. |
| Order card | Shows order code, creation date, quote status badge, quote version, linked design request, total amount, payment deadline, production status, and delivery status. |
| **Chi tiết đơn hàng** | Opens Custom Order Details. |
| **Thanh toán toàn bộ ({amount})** | Shown for unpaid, unexpired quotes; redirects to VNPay for full payment. |
| **Yêu cầu báo giá mới** | Shown when a quote expires to request a new quote. |
| Request card | Shows request code, review status, description, reviewer feedback, and **Xem chi tiết**. |
| **Phản hồi làm rõ** | Opens a dialog to submit a required clarification reply when requested. |
| Empty state | Prompts to create a new design request when no orders or requests exist. |

:::
