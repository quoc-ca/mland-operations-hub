#### 3.1.2 Staff Dashboard

![Staff Dashboard mockup](assets/screens/14-staff-dashboard.png)

This screen allows Staff to:

- Open authorized catalogue maintenance and product-price proposals.
- View permitted workshop sessions and record eligible participant attendance.
- Review design requests within Staff authority and process assigned-branch retail orders.
- Process permitted custom orders and send final-amount proposals to Manager.

| Field Name | Description |
| --- | --- |
| Actions / workshops / open orders | Read-only summary cards restricted to the actor's permitted records; sample counts are not live metrics. |
| Revenue card | Manager-only data. Omit revenue values and access for Member, Staff and Admin. |
| Attention table | Item, responsible actor and status columns; every row must remain within the viewer's authority. |
| Open List | Navigates to an authorized business list, without granting a new permission. |
| Scope and data notices | Display current scope and unavailable or delayed data; illustrative tasks do not confer approval authority. |
