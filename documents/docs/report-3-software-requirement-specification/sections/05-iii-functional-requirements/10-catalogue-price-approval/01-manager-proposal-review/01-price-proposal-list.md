#### 10.1.1 Pending Price Proposals

![](assets/screens/66-price-proposal-list.png)

There is no separate proposal queue: pending retail price proposals are shown to the Manager in the **Đề xuất giá** section of Product Management Details. A product submitted for initial review is flagged "Staff đã gửi duyệt" in Product Management List and opened with **Xem để duyệt**. This screen allows Managers to:

- See, for each size, the applied price and the proposal waiting for a decision.
- Identify who submitted the proposal, from which branch and when, alongside the size's earlier price history.
- Start an approval or a rejection for a single size.
- When two or more sizes are pending, approve or reject them together in the "Giá đang chờ duyệt" panel.

| Field Name | Description |
| --- | --- |
| Size heading | "Size N — Giá đang áp dụng" shows the price customers currently pay; it does not change while the proposal is pending. |
| Pending row | Round marked "(hiện hành)", state Chờ duyệt, proposed amount, no approved amount yet and "Không" under Đã áp dụng. |
| Submitter (Người gửi / Chi nhánh người gửi) | Staff member, branch and submission time. |
| Earlier rounds | Previous proposals with their approved amount, application state and decider. |
| Pending notice | States that the Manager approves (optionally changing the approved price) or rejects here, and that Staff can only view. |
| Duyệt / Từ chối | Manager actions that open Price Proposal Review for the size. |
| Giá đang chờ duyệt (n size) | Shown when at least two sizes are pending: select sizes, enter a common approved price, then approve or reject them together with a shared reason. |
