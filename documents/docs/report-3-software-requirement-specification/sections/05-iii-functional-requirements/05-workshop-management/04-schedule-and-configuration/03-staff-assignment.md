#### 5.4.3 Staff Assignment

![](assets/screens/64-staff-assignment.png)

This screen allows Managers to:

- Select eligible Staff for the target workshop session.
- Review assignment conflicts or overlaps.
- Confirm a valid staff assignment within Manager authority.

| Field Name | Description |
| --- | --- |
| Date / session / branch | Read-only session references; sample times and branches do not establish the operating schedule. |
| Seats / state | Displays configured capacity and occupied/available status while protecting existing bookings and holds. |
| Open Details | Opens an accessible session without changing attendance or capacity. |
| Capacity | Integer configuration input for authorized capacity maintenance. |
| Staff | Selects eligible session staff where assignment authority exists; conflicting assignments must be rejected. |
| Create Session / Save Changes | Manager actions for applicable session configuration; these generic controls are not Staff check-in authority. |
