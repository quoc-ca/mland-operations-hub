#### 5.3.1 Workshop Session List

![](assets/screens/51-workshop-session-list.png)

This screen allows Staff and Managers to:

- See the workshop sessions from today onward, filtered by date range, state and branch.
- See counts of all sessions, sessions on sale, sessions in progress and sessions with attendance finalized.
- Open a session to run check-in and attendance.

A Staff member sees only the sessions a Manager assigned to them and the names of their own branches; a Manager sees all sessions. The list is read-only.

| Field Name | Description |
| --- | --- |
| Scope note | Staff: "Chỉ hiện các ca bạn được Manager phân công." with "Chi nhánh của bạn". Manager: a note on coordinating capacity, check-in and attendance. |
| Metrics | "Tất cả các ca", "Đang mở bán", "Đang diễn ra" and "Đã chốt" counts of the listed sessions. |
| Từ / Đến | Workshop date range; "Từ" starts at today. Filters are kept in the page URL. |
| Trạng thái | All states, "Đang mở bán", "Tạm dừng bán", "Đang diễn ra" or "Đã chốt điểm danh". |
| Chi nhánh | All branches or one branch the user may see. |
| Xóa lọc | Clears all filters. |
| Danh sách ca | Columns Ngày, Giờ, Ca (slot and session id), Chi nhánh, Sức chứa and Trạng thái, 15 sessions per page. |
| Mở | Opens Session Details / Check-in. |
| Empty state | Staff: no assigned session, contact a Manager. Manager: no session matches the filters. |
