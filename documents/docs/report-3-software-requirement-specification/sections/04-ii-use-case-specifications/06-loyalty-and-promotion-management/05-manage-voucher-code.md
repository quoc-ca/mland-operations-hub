### 6.5 Manage Voucher Code

| Use Case ID | UC-46 | Use Case Name | Manage Voucher Code |
| --- | --- | --- | --- |
| Created By |  | Created Date |  |
| Primary Actors | Manager | Secondary Actors | Product Management, Workshop Management |

#### Description

As a Manager, I want to create, monitor, edit, pause, and resume product and workshop vouchers so that Members can redeem promotional codes.

#### Trigger

A Manager opens the Promotion List to create or manage a voucher.

#### Preconditions

1. The Manager is signed in, the account is active, and the role is Manager.

#### Postconditions

1. Each voucher has a unique, immutable code that is never reused.
2. Accepted orders and bookings retain the discount and conditions recorded at acceptance.

#### Normal Flow

**Create Product Voucher**

1. Manager selects New product voucher on the Promotion List.
2. System opens the Promotion Form and generates an `ML` voucher code.
3. Manager enters name, period, scope, discount settings, usage limits, point rule, and distribution.
4. System validates the data, scope, and code uniqueness.
5. System saves the voucher, records a change log, and confirms with the code (MSG38).

**Create Workshop Voucher**

1. Manager selects New workshop voucher on the Promotion List.
2. System generates an `ML` voucher code.
3. Manager enters name, booking period, workshop scope, discount settings, usage limits, point rule, and distribution.
4. System validates and saves the voucher as in Create Product Voucher (MSG38).

**View, Edit, Pause or Resume Voucher**

1. Manager filters the Promotion List and opens a voucher in Promotion Details.
2. System displays conditions, distribution, period, limits, usage counts, and unavailable-product warnings (MSG44).
3. Manager edits allowed conditions, pauses the voucher, or resumes a paused voucher.
4. System validates and saves the change for future transactions (MSG43).

#### Alternative Flows

View 2a. Branch in product voucher scope becomes inactive → System keeps voucher active and displays a warning.

View 2b. Workshop booking using voucher is validly cancelled → System excludes booking from counts unless voucher already expired.

Edit 3a. Manager changes a fixed discount amount → System resets the cap equal to the new amount.

Edit 3b. Manager resumes a paused voucher → System reuses code, history, and counts without extending validity.

#### Exception Flows

1a. Actor is not a Manager, session expired, or save failed → System rejects or reports unconfirmed result (MSG01, MSG02, MSG04).

Create 4a. Generated code already exists → System regenerates up to 3 times; persistent collision fails (MSG39).

Create 4b. Fields or scope are invalid → System rejects the request with field or scope errors (MSG08, MSG40).

Edit 3a. Manager attempts to change code, scope, or distribution → System rejects the change (MSG41).

Edit 3b. New limit is below used, held, and saved counts → System rejects the limit and shows current counts (MSG42).

#### Business Rule Definitions

| ID | Rule Definition |
| --- | --- |
| BR-46-01 | Only a Manager may create, edit, pause or resume vouchers; Admin has no promotion permission. |
| BR-46-02 | Voucher codes are generated by the system, unique across all vouchers after trimming and ignoring case, never changed and never reused. |
| BR-46-03 | Discount amounts and caps are positive whole VND; a cap is entered only for a percentage, and for a fixed amount it is stored equal to the amount. Percentages are greater than 0 up to 100%, minimum amounts are whole VND of 0 or more, and use limits are positive whole numbers. |
| BR-46-04 | The code, the scope, including the branch scope of a product voucher, and the distribution cannot change after creation; total and per-Member limits cannot be lowered below the current used plus held uses, and, for a Must-be-saved voucher, the total limit also counts the saved but unused uses. A Must-be-saved voucher allows one use per Member. |
| BR-46-05 | Pausing, resuming, editing or expiry never changes discounts already accepted; resuming keeps the same code, history and counts and does not extend the voucher. |
