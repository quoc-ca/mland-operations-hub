## 4. Design Request and Human Review (Feature-004)

> **Current baseline (confirmed 2026-11-25):** Basic AI chat (use case 33, section 4.1) stays in scope for Guest and Member. AI image analysis (use case 34, section 4.2) and AI price suggestion (use case 35, section 4.3) are Retired. Feature-004 is a Member-only custom design request with up to five images and no AI provider or automated image/design evaluation; Staff or a Manager reviews it by hand and accepts it, rejects it or requests clarification with a mandatory explanation (sections 5.4 to 5.6). The retired child sections remain as history until the report is structurally migrated.

> **2026-11-22 terminology and reference update:** The customer flow is named
> **Yêu cầu chế tác**. It may include an owner-visible Feature-012 design in
> any readable state; the request stores an immutable snapshot. The saved-design
> page can open a Feature-013 consultation for a signed-in Member.
