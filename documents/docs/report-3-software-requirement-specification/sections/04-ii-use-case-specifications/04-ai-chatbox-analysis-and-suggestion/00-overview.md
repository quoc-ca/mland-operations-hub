## 4. Basic AI Support and Design Request Human Review

Basic AI text support is documented by use case 33 and is separate from
Feature-004. It answers approved public product, workshop and store-information
questions; it does not analyze images, evaluate custom designs, set prices or
make business decisions.

Feature-004 is the Member-only custom design request flow. A Member may submit
text, up to five reference images after affirmative image-processing consent,
and/or an immutable Feature-012 design snapshot. Staff or Manager reviews the
request manually and records an explanation for every acceptance, rejection or
clarification decision. An accepted request proceeds to quote preparation,
Manager approval, one full payment before quote expiry, production and
fulfilment. Guests see the entry point and sign-in prompt only.

> **2026-11-22 terminology and reference update:** The customer flow is named
> **Yêu cầu chế tác**. It may include an owner-visible Feature-012 design in
> any readable state; the request stores an immutable snapshot. The saved-design
> page can open a Feature-013 consultation for a signed-in Member.
