# Definitions and Acronyms

| Term | Meaning |
| --- | --- |
| Guest | Customer who can make a workshop booking without a system account. |
| Member | Customer with a system account; may use Member-only ready-ring retail and view permitted history. |
| Deposit | 50% of the workshop package price, due after a booking invoice is created. |
| Continuation booking | A booking created by Staff for a customer to continue work on a stored work-in-progress item. |
| Handoff | Recorded transfer of a paid ready-ring order to a third-party carrier; V1 does not track the shipment after this point. |
