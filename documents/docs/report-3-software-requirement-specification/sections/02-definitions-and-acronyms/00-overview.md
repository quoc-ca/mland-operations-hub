# Definitions and Acronyms

::: {.docx-table width="100%" columns="20%,80%" repeat-header="false"}

| Acronym | Definition |
| :---: | --- |
| Admin | System administrator who manages accounts, roles, locations and operational parameters, without business authority |
| AI | Artificial Intelligence |
| API | Application Programming Interface |
| Audit log | Append-only record of the actor, time and outcome of each controlled operation |
| Booking group | All workshop tickets confirmed together in one booking |
| BR | Business Rule (use-case level) |
| Carrier | GHTK partner account that records courier pickup and delivery of GHTK shipments |
| COD | Cash on Delivery |
| Custom design request | A Member's description, reference images and optional saved design, reviewed by hand by Staff or Manager |
| DBR | Data Business Rule |
| Deposit | The booking-time collection of a workshop ticket: its final price up to 200,000 VND |
| ERD | Entity Relationship Diagram |
| ERP | Enterprise Resource Planning |
| FAQ | Frequently Asked Questions |
| FR | Functional Requirement |
| GBR | Global Business Rule |
| GHTK | Giao Hang Tiet Kiem, the delivery provider used for retail delivery |
| Guest | Customer without a system account who can browse, use basic AI chat support and book a workshop |
| Handoff | Recorded transfer of a prepared order to the customer at pickup or to the GHTK courier for delivery |
| Hold | Temporary reservation of capacity or stock while a payment is open; it is released when no valid confirmation arrives in time |
| HTTP | Hypertext Transfer Protocol |
| IPN | Instant Payment Notification, the signed server-to-server payment result from VNPay |
| JPEG / PNG | Image file formats accepted for uploads |
| JSON | JavaScript Object Notation |
| KPI | Key Performance Indicator |
| Loyalty points | Points a Member earns on paid retail orders and workshop tickets and may redeem under the point policy |
| Manager | Store operations manager who runs workshops, approves products, prices and quotes, and manages promotions |
| Member | Customer with a system account; may buy ready rings, design rings, use loyalty benefits and view own history |
| MSG | System message code |
| NFR | Non-Functional Requirement |
| OTP | One-Time Password |
| PPSWBS | Personalized Product Sales and Workshop Booking System |
| QR | Quick Response code |
| QueryDR | VNPay transaction status query used to confirm an unconfirmed payment |
| Quote | The Manager-approved price for an accepted custom design request, paid in full in one VNPay payment |
| Ring design | A ring configured by a Member from system-provided options and saved with a recommended workshop |
| Session | A scheduled workshop occurrence at one location, date and time slot, with limited capacity |
| SKU | Stock Keeping Unit |
| SMTP | Simple Mail Transfer Protocol |
| SRS | Software Requirement Specification |
| SSO | Single Sign-On |
| Staff | Branch employee who works only within the one Workshop Location assigned to the account |
| TLS | Transport Layer Security |
| UAT | User Acceptance Testing |
| UC | Use Case |
| UI | User Interface |
| UID | Unique Identifier of a Firebase identity |
| URL | Uniform Resource Locator |
| VND | Vietnamese Dong |
| VNPay | Vietnam Payment gateway used for all online payments |
| Voucher | A saved discount with conditions that a Member applies at checkout or workshop booking |
| Workshop Location | A branch where workshops run, products are stocked and pickup orders are collected |
| Workshop package | A sellable workshop offer with its price, duration, included materials and terms |

:::
