# **Part 0 — Document Overview**

This SRS initially covers the 15 September 2026 V1 baseline: group-session booking, optional ring design, feasibility triage, estimate, two fulfilment modes, final-price consent, and manual collection payment. The 16 September stakeholder inputs propose guest location selection, three-session operating hours, staff-confirmed additional-participant fees, and staff-created continuation bookings with work-in-progress custody; these remain pending approval and detailed rules.

Google Reviews visibility is a research-gated owner/manager dashboard candidate, not an approved payroll or bonus automation feature. Staff/HR management, broader retail, inventory, production scheduling, payment-gateway integration, accounting, and CAD/3D tooling are excluded.

Each accepted requirement must map to a Vision & Scope feature, use case or scenario, business rule, data requirement, non-functional requirement where applicable, design artefact, and test evidence through the Requirements Traceability Workbook.
