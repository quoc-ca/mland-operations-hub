# **Part 0 — Document Overview**

This SRS initially covers the 15 September 2026 V1 baseline: group-session booking, optional ring design, feasibility triage, estimate, two fulfilment modes, final-price consent, and manual collection payment. Staff/HR management, broader retail, inventory, production scheduling, payment-gateway integration, accounting, and CAD/3D tooling are excluded.

Each accepted requirement must map to a Vision & Scope feature, use case or scenario, business rule, data requirement, non-functional requirement where applicable, design artefact, and test evidence through the Requirements Traceability Workbook.
