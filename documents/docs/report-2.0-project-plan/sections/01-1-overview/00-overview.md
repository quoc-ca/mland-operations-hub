# **1\. Overview**

MOH is in Iteration 1 discovery. The project team will use workshop evidence and lecturer feedback on 12 September 2026 to establish the first approved scope baseline. No detailed iteration allocation, budget, or staffing plan is approved yet.

The current delivery milestones are: deploy a usable system by the end of Week 9; use Weeks 10–11 for hardening; then run a live pilot with workshop staff and real customers during Weeks 12–15 to collect operational measures and make necessary maintenance changes.
