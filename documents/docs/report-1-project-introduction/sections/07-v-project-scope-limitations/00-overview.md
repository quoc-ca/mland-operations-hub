# V Project Scope and Limitations {#v-project-scope-and-limitations}

The active V1 baseline begins on 15 September 2026. It is centred on a customer journey for personalised rings: group-session booking, optional design before or during consultation, feasibility decision, estimate, fulfilment, and collection payment. Group decisions on 17 and 18 September approve the booking and session rules, attendance-fee boundary, continuation and custody direction, catalogue and AI routing, conditional Google Review import, and no-expiry ready-ring reservation described in this report. Exact operating data and unresolved integration and governance rules remain open rather than becoming commitments.

The following feature and exclusion lists define the current boundary. Any change requires a recorded group decision and a corresponding update to requirements traceability.
