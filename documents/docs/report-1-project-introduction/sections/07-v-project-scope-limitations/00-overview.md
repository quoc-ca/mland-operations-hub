# V. Project Scope & Limitations {#project-scope-limitations}

The V1 baseline begins on 15 September 2026. V1 covers three customer journeys – workshop booking, ready-made ring sales, and custom ring orders – plus the account, notification, loyalty, review, and reporting functions that support them. Branches, time slots, and session capacities are configuration data managed by the Manager, not fixed values. Every feature below traces to a gap in Section III.
