# Definition and Acronyms {#definition-and-acronyms}

| Acronym or term | Definition |
| --- | --- |
| AI | Artificial intelligence. In V1, the AI Vision API returns candidate ring features and image-quality information only. |
| API | Application Programming Interface. |
| Guest | A customer who uses the booking journey without creating a system account. |
| Member | A customer with a system account who can use the booking journey and buy a ready-made ring. |
| Owner | The business role responsible for catalogue, component-price, feasibility-rule, and override governance. |
| Staff | The shop role that supports workshop operations, consultation, check-in, custody, and settlement records. |
| TBD | To be determined by a future group decision or evidence review. |
| V1 | The active first-version project baseline. |
