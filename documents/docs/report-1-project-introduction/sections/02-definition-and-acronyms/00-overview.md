# Definition and Acronyms {#definition-and-acronyms}

| Acronym | Definition |
| --- | --- |
| AI | Artificial intelligence. Basic AI Support is a separate public FAQ/catalogue capability; it does not analyse Feature-004 images, review designs, quote, price, or make business decisions. |
| API | Application Programming Interface. |
| Guest | A customer who uses the system without creating a system account. A Guest may view public content, use permitted public support, and preview protected feature entry points, but must sign in as a Member before using private design, review, configuration, or consultation actions. |
| Member | A customer with an active system account who can create design requests, save configured designs, create or edit eligible reviews, request a custom-manufacturing order, book workshops, and buy ready-made rings. |
| Design Request | A customer-submitted description and/or reference images that require Staff or Manager human review. It is not an AI decision or a configured workshop design. |
| Custom Order | A shop-made custom-manufacturing order created after an eligible Member's design request is accepted and quoted. It is paid in full after quote approval and is not added to the retail cart. |
| Workshop Recommendation | An advisory package suggestion produced from a saved Feature-012 design. It does not create or modify a booking, payment, or order. |
| Consultation Chat | A Member-only conversation with Staff or Manager for design guidance. It may include a safe Feature-004 or Feature-012 context but does not approve designs, set prices, or mutate booking, payment, or order state. |
| Manager | The business role responsible for workshop operations, Staff assignments, capacity, materials, promotions, published prices, quotes, and business decisions. |
| Admin | The technical role responsible for user accounts, RBAC, integration credentials, monitoring, and technical audit; it does not make routine business or financial decisions. |
| Staff | The shop role that supports consultation, workshop operations, check-in, custody, human design review, and fulfilment records. |
| TBD | To be determined by a future group decision or evidence review. |
| V1 | The active first-version project baseline. |
