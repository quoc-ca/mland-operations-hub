# Definition and Acronyms {#definition-and-acronyms}

| Acronym / Term | Definition |
| --- | --- |
| PPSWBS | Personalized Product Sales and Workshop Booking System, the system built in this project. |
| Mland | The jewellery workshop business that is the client of this project. |
| Guest | A customer without a signed-in account. A Guest can browse public content and book a workshop. |
| Member | A customer with an active account. A Member can also buy ready-made rings, save designs, submit design requests, chat, and write reviews. |
| Staff | A shop employee who works within assigned branches: check-in, counter payment, design review, consultation, and order preparation. |
| Manager | The business role that owns workshop schedules, capacity, prices, quotes, promotions, refunds, and the dashboard. |
| Admin | The technical role that manages accounts, roles, and the ring-difficulty policy. Admin makes no business or financial decision. |
| Carrier | The delivery-partner account that records courier pickup and delivery of an order. |
| Workshop package | A workshop programme with a price per person and a required number of sessions. |
| Workshop session | One branch, one date, and one time slot, with a fixed capacity. |
| Booking group | All workshop tickets confirmed in one cart and one payment. |
| Ticket | The right of one participant to attend the sessions of a package. Each ticket has a QR code and its own bill. |
| Booking-time collection | The amount paid when booking: the full price up to 200,000 VND, otherwise a 200,000 VND deposit per ticket. |
| Workshop ring | A ring the customer makes by hand during a workshop. |
| Custom order | A ring made by the shop after a design request is accepted and its quote is paid in full. |
| Ready-made ring | A published catalogue ring sold through the retail cart. |
| Design request | A Member's description and/or up to five reference images, reviewed by Staff or Manager. |
| RBAC | Role-Based Access Control. |
| VNPay | The Vietnamese online payment gateway used for all online payments. |
| IPN | Instant Payment Notification, the signed server-to-server payment result sent by VNPay. |
| GHTK | Giao Hàng Tiết Kiệm, the delivery provider used for shipping-fee quotes. |
| SMTP | Simple Mail Transfer Protocol, used to send business emails. |
| OTP | One-Time Password. |
| QR | Quick Response code. |
| FE | Feature identifier in the Major Features table. |
| GAP | Gap identifier in the Identified Gaps table. |
| LI | Limitation identifier in the Limitations & Exclusions table. |
| V1 | The first released version of the system, delivered by this project. |
| TBD | To be determined. |
