## 3. Domino's Build Your Own Pizza {#dominos-build-your-own-pizza}

Domino's Build Your Own Pizza is a guided product-customization flow that lets
customers choose a base pizza and then select controlled options such as size,
crust, sauce, toppings, and quantity before placing an order. It is a useful
comparison for Mland because it turns a product idea into a sequence of explicit
choices rather than requiring the customer to describe everything informally.

::: {.docx-table width="100%" columns="35%,65%" repeat-header="false"}

| Criteria | Details |
| --- | --- |
| Website / Link | https://www.dominos.com/ - Build Your Own Pizza flow |
| Target Users | Customers ordering a pizza online and store staff fulfilling a predefined menu configuration |
| Core Features | Base-product selection, step-by-step customization, controlled components, quantity selection, immediate order summary, and checkout |
| Strengths | Makes customization easy to understand, constrains choices to available options, provides immediate feedback, and reduces ambiguity between the customer order and the fulfilment process |
| Weaknesses | Assumes a predefined menu and production process; it does not handle reference-image quality, uncertain ring feasibility, Staff/Manager design review, custom quotation, workshop recommendation, or a Member-owned design history |
| GAP for this project | Domino's demonstrates guided component-based customization, but it cannot manage Mland's Member-only ring configuration, human review, clarification, quote approval, full-payment deadline, workshop recommendation, and accountable custom-manufacturing history. |

:::
