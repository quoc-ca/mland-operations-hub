## 3. Domino's Build Your Own Pizza {#dominos-build-your-own-pizza}

Domino's Build Your Own Pizza is an online configurator. The customer picks a base product, chooses size, crust, sauce, and toppings step by step, and sees the price before ordering.

::: {.docx-table width="100%" columns="35%,65%" repeat-header="false"}

| Criteria | Details |
| --- | --- |
| Website / Link | https://www.dominos.com |
| Target Users | Customers ordering food online |
| Core Features | Base-product selection, step-by-step options, live price, order summary, checkout |
| Strengths | Turns a vague idea into explicit choices, limits choices to what can be made, shows the price immediately |
| Weaknesses | Assumes every combination can be produced at once; no human review, no quote, no reference images, no link to workshops |
| GAP for this project | A ring design may need human review, clarification, and a quote before it can be made, and should guide the customer to a suitable workshop (GAP-01, GAP-03). |

:::
