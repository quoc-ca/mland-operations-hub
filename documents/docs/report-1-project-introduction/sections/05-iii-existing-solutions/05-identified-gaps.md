### Identified Gaps {#identified-gaps}

::: {.docx-table width="100%" columns="15%,25%,60%" repeat-header="false"}

| Gap Code | Gap Name | Description |
| --- | --- | --- |
| GAP-01 | Fragmented customization context | Ring ideas, reference images, saved configurations, review decisions, and quotes are spread across chats instead of one record. |
| GAP-02 | Disconnected workshop booking | Customers cannot see real availability, book a group, and pay a deposit online; Staff lack one view of capacity and check-in. |
| GAP-03 | Unstructured design review and quotation | There is no structured way to review a design request, explain the decision, issue a quote, and show the result to the customer. |
| GAP-04 | Untraceable payment and fulfilment | Deposits, final payments, refunds, order preparation, pickup, and delivery cannot be traced back to the booking or order. |
| GAP-05 | Limited self-service and feedback | Customers must message Staff to check status, and cannot read or leave reviews in the shop's own channel. |
| GAP-06 | Unclear roles and missing overview | Staff, Manager, and Admin responsibilities are not separated, and the Manager has no overview of revenue and operations. |
| GAP-07 | No Member retention tools | Points, vouchers, and promotions are not managed consistently for returning customers. |

:::
