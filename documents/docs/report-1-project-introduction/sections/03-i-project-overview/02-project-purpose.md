## 2. Project Purpose {#project-purpose}

The purpose of this project is to help Mland manage the operational process around personalised rings in one coherent system. The system brings together workshop booking, design input, customization, feasibility review, estimation, payment, fulfilment, and history so that a request does not remain fragmented across messages, calls, images, and informal notes. It is designed to reduce the gap between what a customer imagines, what the shop can make, and what the shop can accurately quote and deliver.

For customers, the project provides a bilingual journey in which they can choose a workshop location and session, select an existing design, configure available components, or request an in-person consultation. Only Members may submit a reference image with consent for AI-assisted analysis or create a separate shop-made custom-manufacturing order. For Mland's Staff and Manager, it provides a shared operational record for understanding the request, reviewing feasibility, maintaining design and estimate context, recording payment and fulfilment decisions, and preserving the reasons for authorised changes or overrides. The same foundation also supports Member purchases of ready-made rings and connects relevant booking, invoice, settlement, custody, and order information.

The project is intended to support human decision-making rather than replace it. AI may assist with extracting candidate features from a Member's reference image and may provide pricing suggestions for selected catalogue items, but these suggestions are advisory only and do not determine the final price. The feasibility engine may help route requests using Manager-approved business rules, while Staff and Manager remain responsible for the reviews and decisions that require business judgement. Admin Technical is responsible for technical configuration rather than routine business or financial approval. Accordingly, V1 focuses on creating a structured and traceable customization workflow for rings.
