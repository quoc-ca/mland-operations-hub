## 2. Project Purpose {#project-purpose}

The purpose of this project is to help Mland manage the operational process around personalised rings in one coherent system. The system brings together workshop discovery, design configuration, design-request review, quotation, payment, fulfilment, and history so that a request does not remain fragmented across messages, calls, images, and informal notes. It is designed to reduce the gap between what a customer imagines, what the shop can make, and what the shop can accurately quote and deliver.

For customers, the project provides a bilingual journey in which they can discover a workshop, view public reviews, see the ring-configuration and custom-request entry points, and sign in when they want to use a protected feature. Only an active Member may configure and save a ring, submit a design request with a description and/or up to five images, create or edit an eligible review, or continue an accepted request into a shop-made custom-manufacturing order. For Staff and Manager, the system provides a shared record for reviewing requests, writing mandatory explanations, preparing quotes, recording payment and fulfilment decisions, and preserving the reasons for authorised changes.

The project supports human decision-making rather than replacing it. Feature-004 contains no AI analysis, AI pricing, or automated design decision. Staff and Manager remain responsible for business review, while Admin Technical manages technical configuration, integration credentials, monitoring, and technical audit without replacing business or financial approval. V1 therefore focuses on a structured, accountable, and traceable customization workflow for rings.
