## 2. Project Purpose {#project-purpose}

The purpose of this project is to develop the Personalized Product Sales and Workshop Booking System (PPSWBS) for Mland, a ring-making workshop. The system lets customers book workshops, buy ready-made rings, and request personalised rings in one bilingual web application. It lets Mland Staff and Managers run sessions, review designs, quote, collect payments, and fulfil orders from one shared record.

This document describes the background, the existing solutions, the proposed solution, and the V1 scope. It serves as the baseline for the requirements, design, and test reports that follow.
